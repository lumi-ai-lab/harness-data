# 全国（不含港澳）全品类经营分析深度报告

## 一、报告概述

本报告基于全国（不含港澳）全品类业务核心指标体系，从**用户渗透、品效（经营效益）、供应链保障**三大维度，对 2026 年 5 月的业务表现、指标波动及深层驱动因素进行系统性拆解与诊断，为后续运营策略优化提供数据支撑与决策依据。

- 时间口径：2026 年 5 月（月份）
- 筛选口径：全国（不含港澳），全品类
- 品类口径：全品类
- 数据来源：`qdm-cmr-cli report business overview/indicators/tree/area/category/trend`
- 总体判断：**用户规模环比改善但同比承压，品效稳步提升，供应链履约质量全面下滑，呈现"前端扩张、中端提效、后端拖累"的分化格局。**

`客数渗透率 → 销售额、客数、客单价 → 19点前销售转化链路 → 全链路毛利率/毛利额 → 商品订购渗透`

### 2. 核心子指标表现与诊断

#### （1）规模类指标：销售额与客数

- **销售额**：12364.50，环比↑3.28%，同比↓2.91%
  - 诊断：销售额环比显著回升，反映本月经营活跃度回暖，但同比仍为负增长，整体规模尚未恢复至去年同期水平，增长基础不稳固。

## 六、关键问题与根因分析

### 1. 用户侧核心问题：以价换量，复购下滑，订购基础收缩

- **核心症状**：客数同比↑6.02% 但客单价同比↓8.42%，销售额同比↓2.91%；19点前复购率环比↓8.68pp；商品订购渗透率同比↓3.1pp，订购门店数同比↓8.71%，可订门店数环比↓4.99%。
- **根因推导**：
  1. 现象：客数同比增长但客单价和销售额同比下降，呈现"增量不增收"格局；影响：用户规模扩张无法转化为销售额增长，单客价值持续摊薄，整体营收增长缺乏动力；推断：促销折扣率同比↑3.78pp 是客单价下滑的主要推手，低价促销策略在吸引用户的同时压低了客单价值，形成"促销依赖症"。
  2. 现象：19点前复购率环比大幅下降 8.68pp；影响：用户回访意愿减弱，用户粘性和生命周期价值下降，前端引流效果可能因复购不足而被抵消；推断：促销吸引的可能是价格敏感型一次性用户，而非高粘性复购用户，用户质量需要关注。
  3. 现象：可订门店数同环比双降（环比↓4.99%，同比↓1.69%），订购门店数同比↓8.71%；影响：订购场景的供给端基础设施在收缩，制约订购渗透率的恢复和增长空间；推断：承接订购业务的门店网络在主动或被动的收缩，可能是门店策略调整或部分门店退出订购体系。

### 2. 品效侧核心问题：促销加码侵蚀毛利，损耗扩大拖累品效

- **核心症状**：促销折扣率同比↑3.78pp 至 10.06%，时段折扣率同比↑0.19pp；定价毛利率环比↓0.64pp，全链路毛利率环比↓1.1pp；损耗率同比↑0.86pp 至 3.19%，出库折让率同比↑1.1pp。
- **根因推导**：
  1. 现象：促销折扣率大幅攀升，定价毛利率、全链路毛利率环比下滑；影响：促销力度加大直接压缩了盈利空间，以利润换规模的特征明显，品效的环比提升更多来自采购成本下降而非盈利改善；推断：当前品效提升的主要驱动力来自采购价格指数下行（采购成本降低），而非定价能力或折扣管控的改善，品效增长质量需警惕。
  2. 现象：损耗率同环比双升（同比↑0.86pp），出库折让率同比↑1.1pp；影响：损耗和折让双重侵蚀，直接拉低品效的实际水平，抵消了采购成本下降带来的正向贡献；推断：仓储配送环节的商品管理存在漏洞，损耗管控和出库折让管理需要系统性加强。

### 3. 供应链侧核心问题：履约质量全面下滑，集采集中度弱化

- **核心症状**：三率综合得分同比↓1.48，准点率同比↓3.75pp 至 93.08%，准确率同比↓0.69pp 至 98.04%；集采入库占比同比↓0.92pp 至 14.92%。
- **根因推导**：
  1. 现象：准点率同比大幅下滑 3.75pp，准确率持续下降；影响：供应商交付不及时、不准确将直接影响门店补货效率、库存周转和商品新鲜度，最终传导至用户满意度和复购率；推断：活跃供应商数增长（↑0.75%）但履约质量下降，说明新引入供应商的交付能力参差不齐，供应商准入和考核标准需收紧。
  2. 现象：集采入库占比持续下滑；影响：集采规模效应减弱，采购议价能力和成本控制能力可能随之下降，与采购价格指数的下行走势形成张力；推断：集采占比下降可能源于品类结构调整或供应商分散化策略，需明确集采战略方向。

## 七、优化策略与行动建议

### 1. 用户侧：从以价换量转向价值经营

**短期动作**
- 针对 19点前复购率环比大幅下滑（↓8.68pp），立即排查复购下降的核心用户群和区域分布，开展定向复购激励活动（如优惠券、积分翻倍），遏制复购率继续下滑；
- 针对可订门店数持续下降（环比↓4.99%），梳理可订门店退出原因，对具备订购承接能力的门店推动回流，保障订购场景的基础设施供给；
- 针对客单价同比↓8.42%，在促销活动中增加满减门槛、套装组合等提升客单价的机制，避免单纯折扣导致客单价持续走低。

**长期动作**
- 建立用户分层运营体系，区分价格敏感型用户和高价值用户，制定差异化触达和促销策略，降低对全面促销的依赖；
- 将 19点前复购率纳入核心运营监控指标，建立复购预警和自动干预机制；
- 推动商品订购场景的门店覆盖扩展，设定可订门店数的底线目标和增长计划。

### 2. 品效侧：管控促销力度，遏制损耗扩大

**短期动作**
- 针对促销折扣率同比↑3.78pp，复盘本月促销活动的 ROI，对低效促销活动进行削减或优化，控制促销力度在合理区间；
- 针对损耗率同比↑0.86pp，对高损耗品类（蔬菜、水果、水产等生鲜品类）进行专项损耗排查，强化仓储温控和配送时效管理；
- 针对出库折让率同比↑1.1pp，审查出库折让的审批流程和折让标准，收紧折让政策。

**长期动作**
- 建立"采购成本下降→终端售价优化→毛利率提升"的良性传导机制，确保采购价格指数的下行能够转化为实际的盈利改善，而非被促销和折让消耗；
- 构建损耗率的品类级监控体系，设定分品类的损耗率红线，超线自动预警并启动整改；
- 将出库折让率纳入品效考核，推动履约端主动管控折让。

### 3. 供应链侧：收紧供应商质量管控，明确集采战略

**短期动作**
- 针对准点率同比大幅下滑（↓3.75pp至93.08%），对低准点率供应商进行专项沟通和整改通知，设定整改期限，整改不达标的暂停订单分配；
- 针对准确率持续下降（↓0.69pp），核查准确率下降的主要供应商和品类，排查发货差错根因；
- 针对三率综合得分持续下滑，在供应商月度评估中提高三率权重，将三率得分与订单分配直接挂钩。

**长期动作**
- 建立供应商分级管理制度，基于三率得分、合作规模、集采参与度等指标，将供应商分为战略/核心/观察/淘汰四级，动态调整订单分配；
- 明确集采战略方向，设定集采入库占比的目标值，推动核心品类向集采集中，提升议价能力和供应稳定性；
- 新供应商准入环节增加履约能力压力测试，避免引入低履约能力的供应商稀释整体质量。

## 八、风险提示与后续跟踪

1. 用户侧：以价换量模式不可持续，若促销力度继续加大而客单价持续走低，将陷入"促销→低价→低利润→更依赖促销"的恶性循环；19点前复购率若继续下滑，用户资产价值将持续缩水；
2. 品效侧：促销折扣率同比已升 3.78pp，若进一步加码，定价毛利率和全链路毛利率将持续承压；损耗率若继续扩大，将直接对冲采购成本下降的利好，品效增长可能失速；
3. 供应链侧：准点率已降至 93.08%，若继续下滑将引发门店缺货、商品新鲜度下降等连锁反应，最终影响用户满意度和复购率，成为全链路的系统性风险。

**重点跟踪指标**
- 用户侧：客数、客单价、19点前复购率、可订门店数、商品订购渗透率
- 品效侧：促销折扣率、损耗率、出库折让率、定价毛利率
- 供应链侧：准点率、准确率、三率综合得分、集采入库占比

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 客数渗透率 | 下单用户数/目标用户数，反映用户覆盖能力 |
| 品效 | 综合反映商品经营效率与盈利水平的核心指标 |
| 活跃供应商数 | 一定周期内有合作行为的供应商数量 |
| 全链路毛利率 | （销售额-全链路成本）/销售额，反映整体盈利水平 |
| 三率综合得分 | 准确率、准点率、合格率的综合评分，反映供应商履约质量 |
| 19点前销售占比 | 19点前销售额/全时段销售额，反映用户消费时段前移程度 |
| 订单满足率 | 实际满足订单数/总订单数，反映履约对用户需求的覆盖能力 |
| 商品订购渗透率 | 发生订购行为的门店数/可承接订购的门店数，反映订购场景覆盖程度 |
| 出库折让率 | 出库环节产生的折让金额/出库金额，反映履约折让损耗 |
| 损耗率 | 仓储配送过程中的商品损耗金额/库存金额，反映商品管理效率 |
