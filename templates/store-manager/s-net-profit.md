# 门店净利润指标分析报告模板

> 说明：本模板用于门店管理下的门店净利润指标专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 门店净利润是门店管理两大一级核心指标之一，反映门店整体盈利水平与健康度。
- 固定拆解链路：`门店净利润 -> 盈亏平衡点、坪效、人效`。
- 本报告核心问题是判断门店净利润当前水平是否达标，同比环比变化方向及幅度，变化是否来自区域结构分化、成本结构变化或趋势异常，以及净利润变化对门店盈利能力的整体影响。
- 区域、趋势证据只用于解释门店净利润及其下钻链路，不扩展为经营总览报告。
- 品类口径固定为全品类，不做品类下钻，不输出品类排名、品类拖累或品类贡献。
- 营业门店数、开店数、闭店数、停业门店数等门店规模指标不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 十、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 门店净利润 | 门店总收入减去门店总成本后的净利润，反映门店整体盈利水平与健康度的核心指标 |
| 盈亏平衡点 | 门店达到盈亏平衡所需的最低销售额或收入水平，反映单店盈利门槛和成本压力 |
| 坪效 | 单位面积产出效率（销售额 / 门店面积），反映门店空间利用效率 |
| 人效 | 单位人力产出效率（销售额 / 门店人数），反映门店人力投入产出效率 |
| 净增门店数 | 开店数与闭店数之差，反映门店网络净增长 |
| 开店数 | 新增开业门店数量 |
| 闭店数 | 已关闭或退出经营的门店数量 |
| 待开业门店数 | 已签约或筹备中但尚未开业的门店数量 |
| 停业超30天门店数 | 连续停业超过30天的门店数量 |
