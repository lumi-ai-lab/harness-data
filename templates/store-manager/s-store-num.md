# 门店人数指标分析报告模板

> 说明：本模板用于门店管理下人效维度的门店人数（`storeNum`）专项分析报告。所有数值、同比、环比、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 门店人数是人效的一级子指标，作为人效计算的分母（人效 = 门店净利润 / 门店人数），反映门店人力配置规模。
- 固定拆解链路：`门店净利润 -> 人效 -> 门店人数`。门店人数是叶子指标，无进一步下钻。
- 本报告核心问题是判断门店人数当前水平是否达阈值（<= 5），同比环比变化方向及幅度，变化是否来自区域结构分化或趋势异常，以及对父指标人效的传导影响。
- 区域、趋势证据只用于解释门店人数及其父指标，不扩展为门店管理总览报告。
- 营业门店数、开店数、闭店数、停业门店数不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 七、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 门店人数 | 统计周期内门店平均在岗人员数量（店日均口径），是人效计算的分母。人数越低越有利于人效提升。 |
| 人效 | 门店单人均净利润贡献（门店净利润 / 门店人数），反映门店人力投入的产出效率。 |
| 门店净利润 | 人效的父指标，门店管理一级核心指标，反映门店整体盈利水平。 |

> 数据来源优先级：`qdm-cmr-cli report store indicators > area > trend`。所有数值必须在 CLI 返回结果中有据可查。
