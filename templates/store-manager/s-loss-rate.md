# 不良率指标分析报告模板

> 说明：本模板用于门店管理下门店盈利与运营效率维度中不良率链路的专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。
> 品类口径固定为全品类，不输出品类排名、品类拖累或品类贡献。

## 通用填充规则

- 不良率是盈亏平衡点（breakEvenPoint）的子指标，属于门店盈利与运营效率维度下的盈利与成本结构类指标。
- 固定拆解链路：`门店净利润 -> 盈亏平衡点 -> 不良率 -> 头部门店不良率、中上门店不良率、中下门店不良率、尾部门店不良率`。
- 不良率的四个子指标以垂直分组（isGroup: true, layout: vertical）形式展示，不应横向排列。
- 本报告核心问题是判断不良率当前水平是否可控，各梯队门店不良率是否存在结构性恶化，以及不良率上升对门店净利润和盈亏平衡的影响。
- 不良率为反向指标，值越低越好；不良率上升说明门店质量恶化，需重点关注中下和尾部梯队。
- 不良率 valueUnit=3（小数形式的比率），报告中需 ×100 转为百分比展示；同比/环比 unit=3 表示百分点变化。
- 门店净利润和盈亏平衡点只用于父级传导，不能替代当前指标。
- 成本支出指标（员工工资、租金、水电费等）只可在解释不良率根因时作为补充背景，不得作为主指标行。
- 营业门店数、坪效、人效、门店规模与健康度指标不得作为本报告主指标行。
- 区域、趋势证据只能用于解释不良率及其下钻链路，不扩展为经营总览报告。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
