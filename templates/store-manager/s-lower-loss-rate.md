# 中下门店不良率指标分析报告模板

> 说明：本模板用于门店管理下门店盈利与运营效率维度中不良率链路的中下门店不良率专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。
> 品类口径固定为全品类，不输出品类排名、品类拖累或品类贡献。

## 通用填充规则

- 中下门店不良率是不良率（lossRate）的子指标，属于不良率分层指标组的叶子指标。
- 固定拆解链路：`门店净利润 -> 盈亏平衡点 -> 不良率 -> 中下门店不良率`。
- 本报告核心问题是判断中下门店不良率当前水平是否过高，是否存在向尾部恶化的趋势，以及对整体不良率的拖累幅度。
- 不良率为反向指标，值越低越好；中下门店不良率通常显著高于头部和中上梯队，为不良率管控的重点关注梯队。
- 不良率 valueUnit=3（小数形式的比率），报告中需 ×100 转为百分比展示；同比/环比 unit=3 表示百分点变化。
- 门店净利润、盈亏平衡点、不良率只用于父级传导，不能替代当前指标。
- 其余不良率分层子指标（头部、中上、尾部）只可作为同组对比背景，不得替代当前指标。
- 营业门店数、坪效、人效、成本支出指标不得作为本报告主指标行。
- 区域、趋势证据只能用于解释中下门店不良率，不扩展为经营总览报告。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
