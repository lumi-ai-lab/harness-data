# 待开业门店数分析报告模板

> 说明：本模板用于门店管理下的待开业门店数指标专项分析报告。所有数值、同比、环比、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 待开业门店数是开店数（`openStores`）的叶子子指标，反映门店筹建管道储备，无下级拆解指标。
- 本报告核心问题是判断待开业门店数当前储备是否充足，同比环比变化趋势，区域间筹建资源分布是否合理，以及储备量对后续开店节奏的支撑能力。
- 区域、趋势证据只用于解释待开业门店数，不扩展为经营总览报告。
- 销售额、客数、客单价、品效、19点前链路指标、活跃供应商数、三率综合得分不得作为本报告主指标行。
- 品类数据不得放入本报告任何章节（门店管理域不涉及品类维度）。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
