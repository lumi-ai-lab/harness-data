# 开店数分析报告模板

> 说明：本模板用于门店管理下的开店数指标专项分析报告。所有数值、同比、环比、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 开店数是净增门店数（`increaseStores`）的一级子指标，反映门店扩张速度。
- 固定拆解链路：`开店数 -> 待开业门店数`。
- 本报告核心问题是判断开店数当前水平，同比环比变化趋势，开店节奏是否正常，待开业门店数是否充足，以及区域间开店表现分化。
- 区域、趋势证据只用于解释开店数及其下钻链路，不扩展为经营总览报告。
- 销售额、客数、客单价、品效、19点前链路指标、活跃供应商数、三率综合得分不得作为本报告主指标行。
- 品类数据不得放入本报告任何章节（门店管理域不涉及品类维度）。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
