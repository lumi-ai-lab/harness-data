# 坪效指标分析报告模板

> 说明：本模板用于门店管理下的坪效指标专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 坪效是门店管理门店净利润（`netProfit`）的下钻子指标之一，反映门店空间利用效率。
- 固定拆解链路：`坪效 -> 门店面积（storeArea）`。
- 本报告核心问题是判断坪效当前水平及变化方向，同比环比变化幅度，变化是否来自区域结构分化或趋势异常，以及坪效变化对门店运营效率的整体影响。
- 区域、趋势证据只用于解释坪效及其下钻链路，不扩展为经营总览报告。
- 门店净利润、盈亏平衡点费用组指标不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

| 门店面积 | 门店营业面积（平方米），统计周期内门店实际营业面积 |
| 门店净利润 | 门店维度的净利润，反映门店整体盈利能力 |
