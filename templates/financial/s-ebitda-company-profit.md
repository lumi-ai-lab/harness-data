# EBITDA指标分析报告模板

> 说明：本模板用于公司报表下的EBITDA专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- EBITDA 是公司报表 `/report/4` 的一级核心指标，反映公司的税息前利润水平，是衡量公司整体盈利能力的关键指标。
- 固定拆解链路：`EBITDA -> 公司营业收入、公司毛利额、费率 -> 供应链收入(财务)、直营店收入、品牌管理&加盟费、其他业务收支净额、供应链毛利额、直营店毛利额、宣传促销补贴费率、运输费率、租金费率、人员费用率、其他费用率`。
- 本报告核心问题是判断EBITDA当前水平，同比环比变化方向及幅度，变化主要来自收入端（公司营业收入及其子项）、毛利端（公司毛利额及其子项）还是费用端（费率及各费用率子项）。
- 公司报表无品类维度，不分析品类结构。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
- `companyProfit` 下的 `financeScmProfit` 和 `directStoreProfitAmt` 的 `lineType` 为 `dashed`，作为辅助参考线，不单独成章。

## 十一、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| EBITDA | 税息前利润 = 公司其他收入+门店业务毛利-费用总额-折旧及摊销，反映公司整体盈利能力 |
| 公司营业收入 | -加盟费用收入+供应链收入+直营门店收入+品牌使用费收入-直营门店成本+职能部门收入+（-其他收入-其他支出） |
| 供应链收入(财务) | 公司财务口径下的供应链业务收入 |
| 直营店收入 | 公司直营门店产生的业务收入 |
| 品牌管理&加盟费 | 品牌使用费+加盟费收入，反映品牌和加盟体系的变现能力 |
| 其他业务收支净额 | 除供应链、直营、加盟费以外的其他业务收入与支出的净额 |
| 公司毛利额 | 公司营业收入减去对应成本后的毛利金额 |
| 供应链毛利额 | 供应链业务产生的毛利金额（lineType: dashed） |
| 直营店毛利额 | 直营门店业务产生的毛利金额（lineType: dashed） |
| 费率 | 总费用率 = 总费用额 / 公司营业收入，反映费用对收入的侵蚀程度 |
| 宣传促销补贴费率 | 宣传促销补贴费用占收入的比例（含宣传促销费率和补贴费用率两个子维度） |
| 运输费率 | 运输费用占收入的比例 |
| 租金费率 | 租金费用占收入的比例 |
| 人员费用率 | 人员费用占收入的比例 |
| 其他费用率 | 其他费用占收入的比例 |
