# 租金费额指标分析报告模板

> 说明：本模板用于公司报表下的租金费额专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符。

## 通用填充规则

- 租金费额是公司报表 EBITDA 维度下租金费率的金额子指标。
- 固定拆解链路：`费率 -> 租金费率 -> 租金费额`。
- 核心分析问题：租金费额的当前水平、同比环比变化方向和幅度、区域结构分化。
- 公司报表无品类维度，不分析品类结构。
- 租金费额是金额型叶子指标，统计逻辑为"供应链端租金+运营端租金+总部职能租金"。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑。

## 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 费率 | 期间费用占收入的比例，反映费用管控效率，是租金费额的总纲指标。 |
| 租金费率 | 租金费额的父指标，租金费用占公司收入的比例。 |
| 租金费额 | 租金费用的绝对值 = 供应链端租金 + 运营端租金 + 总部职能租金。 |
| 公司营业收入 | `companyBusinessIncome`，费用率的分母，企业整体收入规模。 |
