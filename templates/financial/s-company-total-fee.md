# 总费用额指标分析报告模板

> 说明：本模板用于公司财务报表费控维度下的总费用额专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`费率 -> 额`。总费用额是费率（companyTotalFeeRate）的金额子指标。
- 本报告核心问题是判断公司总费用支出规模、趋势及其对 EBITDA 的影响。
- 总费用额由五大分项构成：宣传促销补贴费额 + 运输费额 + 租金费额 + 人员费额 + 其他费额。
- 费率只用于父级传导，不替代当前指标。
- 收入类指标（公司营业收入、门店业务收入等）不得作为本报告主指标行。
- 毛利类指标（公司毛利额、供应链毛利额等）不得放入本章节作为主指标行。
- 经营分析类指标（客数、客单价、品效等）不得放入本章节。
- 本指标固定归入财务报告第六章（费用管控维度深度拆解），禁止放入第四章（收入结构）和第五章（毛利贡献）。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
