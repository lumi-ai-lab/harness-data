# 物流费率指标分析报告模板

> 说明：本模板用于公司报表下的物流费率（`companyLogisticsFeeRate`）专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 物流费率（运输费率）是费率（`companyTotalFeeRate`）的子指标，属于费用管控维度 > 分项费用表现指标组。
- 统计逻辑为"物流费 / 出库总额"，比率变化可拆解为分子（物流费额）和分母（出库总额）的分别变动。
- 关联金额子指标 `companyLogisticsFee`（物流费额），可配合查询以获取金额维度的明细，用于解释费率变动背后的金额驱动因素。
- 本报告核心问题是判断物流费率当前水平是否合理，同比环比变化方向及幅度，变化是否来自物流费额的变动还是出库总额的变动，以及物流费率变化对整体费用管控和供应链效率的影响。
- 公司报表无品类维度，不涉及品类拆解。
- 归入费用管控维度，不得放入收入结构或毛利贡献章节。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 物流费率 | 物流费占公司收入的占比，统计逻辑为物流费 / 出库总额，反映供应链物流成本相对于收入规模的负担水平 |
| 物流费额 | 供应链出库仓配到店产生的物流费用，对应财报的供应链-物流费 |
| 出库总额 | 供应链出库商品的总金额，是物流费率的分母 |
| 费率 | 期间费用率，公司报表费用管控维度的总纲指标 |
