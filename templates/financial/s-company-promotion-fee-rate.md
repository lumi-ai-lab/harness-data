# 宣传促销费率指标分析报告模板

> 说明：本模板用于公司财务报表费控维度下的宣传促销费率专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`费率 -> 宣传促销补贴费率 -> 宣传促销费率`。
- 本报告核心问题是判断宣传促销费用占公司收入的比例及其变化趋势。
- 宣传促销费率是宣传促销补贴费率的子指标，叶子节点。
- 父级宣传促销补贴费率只用于父级传导，不替代当前指标。
- 金额子指标（companyPromotionFee）可作为辅助展示，不替代当前指标作为主指标行。
- 补贴费用率可作为同组参考，不替代当前指标。
- 收入类、毛利类指标不得放入本章节作为主指标行。
- 其他费用项（运输费率、租金费率、人员费率、其他费用率）不得放入本章节。
- 本指标固定归入财务报告第六章（费用管控维度深度拆解），禁止放入第四章和第五章。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
