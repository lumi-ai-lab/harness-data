# 其他费用额指标分析报告模板

> 说明：本模板用于公司报表下的其他费用额专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符。

## 通用填充规则

- 其他费用额是公司报表 EBITDA 维度下其他费用率的金额子指标。
- 固定拆解链路：`费率 -> 其他费用率 -> 其他费用额`。
- 核心分析问题：其他费用额的当前水平、同比环比变化方向和幅度、区域结构分化。
- 公司报表无品类维度，不分析品类结构。
- 其他费用额是金额型叶子指标，统计逻辑为"除物流、租金、人员费用、宣传促销费、补贴费之外的其他费用"。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑。
