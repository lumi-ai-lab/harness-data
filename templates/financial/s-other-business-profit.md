# 其他业务收支净额指标分析报告模板

> 说明：本模板用于公司报表下收入结构维度中的其他业务收支净额专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`公司营业收入 -> 其他业务收支净额`。
- 本报告核心问题是判断其他业务收支净额表现，并说明它对公司营业收入的贡献。
- 本指标固定归入公司财务报告第四章（收入结构维度深度拆解），禁止放入第五章和第六章。
- 不得将毛利贡献维度指标（公司毛利额、供应链毛利额、直营店毛利额）放入本报告作为主指标行。
- 不得将费用管控维度指标（费率、各项费用率/额）放入本报告作为主指标行。
- 公司报表无品类维度，区域表现和趋势证据只用于解释该指标的变化，不扩展为经营总览。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
- 若 CLI 未返回该指标数据，按 contracts 规范省略该章节，不写缺失说明。
