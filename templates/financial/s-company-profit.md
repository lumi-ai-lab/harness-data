# 公司毛利额指标分析报告模板

> 说明：本模板用于公司报表下毛利贡献维度中的公司毛利额专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`EBITDA -> 公司毛利额 -> 供应链毛利额 / 直营店毛利额`。
- 本报告核心问题是判断公司毛利额表现，并说明分业务毛利（供应链、直营店）的贡献结构和传导关系。
- 本指标固定归入公司财务报告第五章（毛利贡献维度深度拆解），禁止放入第四章和第六章。
- 收入结构指标（公司营业收入、供应链收入、直营店收入、品牌管理&加盟费、其他业务收支净额）不得放入本报告作为主指标行。
- 费用管控指标（费率、各项费用率/额）不得放入本报告作为主指标行。
- 公司报表无品类维度。
- 供应链毛利额和直营店毛利额（lineType: dashed）只能作为公司毛利额的分项展示，不可替代主指标。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
