# 费率指标分析报告模板

> 说明：本模板用于公司报表下费用管控维度中的费率专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`EBITDA -> 费率 -> 各项费用率（宣传促销补贴费率、运输费率、租金费率、人员费用率、其他费用率）`。
- 本报告核心问题是判断公司费用管控效率，并说明费率对 EBITDA 的传导影响。
- 费率有配套的金额 subIndicator：`companyTotalFee`（总费用额），两者需联动展示。
- 本指标固定归入公司财务报告第六章（费用管控维度深度拆解），禁止放入第四章和第五章。
- 收入结构指标和毛利贡献指标不得放入本报告作为主指标行。
- 公司报表无品类维度。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
