## 通用填充规则

- 补贴费用额是补贴费用率（`companyAllowanceFeeRate`）的金额子指标（subIndicator），属于费用管控维度 > 宣传促销费用结构指标组。
- 统计逻辑为"新店补贴费用+装修返利补贴费用+其他补贴费用"，三部分构成总补贴费用额。
- 本报告核心问题是判断补贴费用额当前规模和变化方向是否合理，同比变化幅度，以及金额变化对补贴费用率和整体费用管控的影响。
- 公司报表无品类维度，不涉及品类拆解。
- 归入费用管控维度，不得放入收入结构或毛利贡献章节。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 补贴费用额 | 用于给门店经营提供经营支持的补贴费用，统计逻辑为新店补贴费用+装修返利补贴费用+其他补贴费用 |
| 补贴费用率 | 补贴费用占公司收入的占比，是补贴费用额的父指标（率形态） |
| 宣传促销补贴费率 | 宣传促销与补贴合计费率，是补贴费用率的父指标 |
| 费率 | 期间费用率，公司报表费用管控维度的总纲指标 |
