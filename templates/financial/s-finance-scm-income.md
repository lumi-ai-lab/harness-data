## 通用填充规则

- 供应链收入(财务)是公司营业收入下的叶子指标，反映公司财务口径的供应链业务收入规模。
- 固定拆解链路：`EBITDA -> 公司营业收入 -> 供应链收入(财务)`。
- 本报告核心问题是判断供应链收入当前水平，同比环比变化方向及幅度，以及对公司营业收入的贡献度。
- 公司报表无品类维度，不分析品类结构。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 七、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 供应链收入(财务) | 公司财务口径下的供应链业务收入，是公司营业收入的组成部分 |
| 公司营业收入 | -加盟费用收入+供应链收入+直营门店收入+品牌使用费收入-直营门店成本+职能部门收入+（-其他收入-其他支出） |
| 供应链毛利额 | 供应链业务产生的毛利金额，在EBITDA链路中归属于公司毛利额（lineType: dashed） |
| EBITDA | 税息前利润 = 公司其他收入+门店业务毛利-费用总额-折旧及摊销 |
