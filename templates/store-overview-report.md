## 通用填充规则

- 章节标题必须保持 1 到 9 的顺序，两大拆解维度固定为：门店规模与健康度、门店盈利与运营效率。
- 章节、指标归属、指标组和表格结构优先级高于模型自由组织。
- 品类口径固定为全品类，不得根据用户问题生成品类下钻分析。
- 区域口径按用户指定区域填充；若用户未指定区域，固定填充为全国（不含港澳）。
- 只展示 CLI 返回的数据；没有返回的指标行直接省略。
- 某个指标组内没有任何 CLI 返回指标时，可以省略该指标组。
- 额外指标只有在能解释关键门店管理现象时才补充，并放入语义最匹配的小节。
- 诊断语言保持“表现 -> 诊断”；关键问题与根因分析中必须体现“现象 -> 影响 -> 推断”。

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 营业门店数 | 处于正常营业状态的门店数量，反映门店网络规模 |
| 存量门店数 | 已纳入经营管理范围的门店数量，反映门店基础盘规模 |
| 停业门店数 | 当前处于停业状态的门店数量，反映短期运营中断风险 |
| 净增门店数 | 开店数减去闭店数，反映门店网络净增长情况 |
| 开店数 | 统计周期内新增开业门店数量，反映扩张落地情况 |
| 闭店数 | 统计周期内关闭门店数量，反映门店退出和结构优化情况 |
| 待开业门店数 | 已筹备但尚未正式营业的门店数量，反映潜在扩张储备 |
| 停业超30天门店数 | 停业时长超过30天的门店数量，反映长期停业和资源占用风险 |
| 门店净利润 | 门店营业收入扣除所有成本后的利润，反映门店整体盈利水平 |
| 盈亏平衡点 | 门店营收刚好覆盖所有成本的临界值，反映门店盈利门槛 |
| 坪效 | 门店销售额/门店面积，反映单位面积的产出效率 |
| 人效 | 门店销售额/门店人数，反映单位人力的产出效率 |
