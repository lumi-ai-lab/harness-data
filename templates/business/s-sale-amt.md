# 销售额指标分析报告模板

> 说明：本模板用于经营分析下的销售额指标专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 销售额是客数渗透率的子指标，属于规模类指标，用于说明用户规模和经营结果。
- 固定拆解链路：`销售额 -> 19点前销售占比 -> 19点前销售重量、订单满足率`。
- 本报告核心问题是判断销售额当前水平是否达标，同比环比变化方向及幅度，变化是否来自趋势异常或结构性因素，以及销售额变化对用户规模与经营结果的整体影响。
- 区域、品类、趋势证据只用于解释销售额及其下钻链路，不扩展为经营总览报告。
- 销售额归用户渗透维度，品效指标、供应链指标不得作为本报告主指标行。
- 客数、19点前客数、客单价、19点前客单价、全链路毛利率、全链路毛利额及其下游指标不得作为销售额报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 客数渗透率 | 下单客数与门店辐射范围内潜在客数的比率，反映用户覆盖与触达能力的总纲指标 |
| 销售额 | 门店销售商品的总金额（原价销售额减去日结相关优惠金额后的结算金额），反映经营结果 |
| 19点前销售占比 | 清仓时段前销售额占全天销售额的比例（门店19点前销售额 / 销售额），反映用户行为链路的前段转化效率 |
| 19点前销售重量 | 19点前时段的商品销售总重量，用于判断白天前段转化强弱 |
| 订单满足率 | 实际满足订单数与总订单数的比率，反映履约能力对销售的支撑程度 |
