# 集采入库占比指标分析报告模板

> 说明：本模板用于经营分析下供应链维度的集采入库占比专项分析报告。所有数值、同比、环比、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 集采入库占比是活跃供应商数的子指标，属于叶子指标，反映集采集中度与入库协同程度。
- 固定拆解链路：`活跃供应商数 -> 集采入库占比`（叶子，无子指标，无进一步下钻）。
- 本报告核心问题是判断集采入库占比当前水平是否合理，同比环比变化方向及幅度，变化是否来自区域结构分化、品类覆盖率不足或趋势异常，以及集采入库占比变化对活跃供应商数的贡献和影响。
- 区域、品类、趋势证据只用于解释集采入库占比及其对活跃供应商数的贡献，不扩展为经营总览报告。
- 销售额、客数、客单价、19点前链路指标、品效及其下钻指标不得作为本报告主指标行。
- 准确率、准点率、合格率、三率综合得分虽同属供应链维度，但属于履约质量三率指标组，不得混入本报告。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
- 集采入库占比无阈值配置，不进行阈值达标判断。

## 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 集采入库占比（centralInstockRate） | 集采入库金额占整体入库金额的占比，反映集采集中度与入库协同程度。计算逻辑：（集采仓的调拨出库金额（不含税）- 集采仓的调拨退货入库金额（不含税）） / （集采仓的调拨出库金额（不含税）- 集采仓的调拨退货入库金额（不含税）+ 非集采仓的采购入库额（不含税）- 非集采仓的采购退货额（不含税）） |
| 活跃供应商数（activeVenderNum） | 供应链合作广度与稳定性的总纲指标，为集采入库占比的父指标 |
