# 准点率指标分析报告模板

> 说明：本模板用于经营分析下活跃供应商数树中的准点率专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`活跃供应商数 -> 三率综合得分 -> 准点率`。
- 本报告核心问题是判断供应商履约准点率是否达标、是否拖累三率综合得分，并说明对活跃供应商数和供应履约时效的影响。
- 三率综合得分只用于父级传导判断；准确率、合格率只可作为同组对照，不得替代准点率作为主指标。
- 活跃供应商数、集采入库占比、准确率、合格率不得作为本报告主指标行。
- 品效、客数渗透率、销售额、全链路毛利率不得作为本报告主指标行。
- 区域、品类、趋势证据只用于解释准点率的结构分化、履约时效短板和数据异常。
- CLI 返回 null、0 或异常跳点时，只能按 CLI 事实描述为数据异常或结构异常，不得自行修正、平滑或估算。
