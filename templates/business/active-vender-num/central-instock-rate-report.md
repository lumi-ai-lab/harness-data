# 集采入库占比指标分析报告模板

> 说明：本模板用于经营分析下活跃供应商数树中的集采入库占比专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`活跃供应商数 -> 集采入库占比`。
- 本报告核心问题是判断集采入库占比变化来自区域/品类集采集中度变化、趋势波动还是结构性空白，并说明对活跃供应商数和供应链集中采购能力的影响。
- 区域、品类、趋势证据只用于解释集采入库占比，不扩展为经营总览报告。
- 三率综合得分、准确率、准点率、合格率可在风险提示中用于履约质量传导说明，但不得作为本报告主指标行。
- 品效、客数渗透率、销售额、全链路毛利率不得作为本报告主指标行。
- CLI 返回 0、null 或缺失区域/品类时，只能按 CLI 事实描述为结构空白或数据缺口，不得自行补数。
