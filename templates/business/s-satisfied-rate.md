> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 订单满足率是19点前销售占比的子指标，属于19点前链路指标组（用户行为链路），叶子指标，无下钻子指标。
- 固定拆解链路：`客数渗透率 -> 销售额 -> 19点前销售占比 -> 订单满足率`。
- 本报告核心问题是判断订单满足率当前是否在阈值区间内（99.5%~100.5%），同比环比变化方向及幅度，变化是否来自区域结构分化或品类结构变化，以及满足率变化对19点前销售占比和前段转化效率的影响。
- 区域、品类、趋势证据只用于解释订单满足率及其对上层指标的传导贡献，不扩展为经营总览报告。
- 订单满足率明确归用户行为链路，不得放入供应链章节。品效指标、供应链指标（准确率、准点率、合格率等）不得作为本报告主指标行。
- 19点前销售占比和销售额只用于父级传导判断，不得替代订单满足率作为主指标。
- 订单满足率存在区间阈值（BETWEEN 99.5%~100.5%），高于上限和低于下限都按偏离处理，不得简单写成越高越好。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 客数渗透率 | 订单满足率所属的上级经营分析一级核心指标（购买客户数 / 可服务客户数），反映用户覆盖与触达能力 |
| 销售额 | 订单满足率的上级销售规模指标，用于判断订单满足对经营规模的影响 |
| 19点前销售占比 | 订单满足率的父指标（门店19点前销售额 / 销售额），阈值 >78%，用于判断早时段销售结构 |
| 订单满足率 | 满足分拣标准的订单数占门店订购订单数的比例（订单满足次数 / 订购订单次数），阈值区间 99.5%~100.5%，明确归用户行为链路，叶子指标 |
| 19点前销售重量 | 同组早时段成交参考指标（19点前销售数量 * 商品单位重量），用于判断白天前段转化强弱 |
