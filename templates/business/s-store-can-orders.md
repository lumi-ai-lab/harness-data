## 通用填充规则

- 可订门店数是商品订购渗透率的二级子指标，作为渗透率计算的分母，反映具备商品订购条件的门店规模。
- 固定拆解链路：`品效 -> 商品订购渗透率 -> 可订门店数`。可订门店数是叶子指标，无进一步下钻。
- 本报告核心问题是判断可订门店数当前水平、同比环比变化方向及幅度，变化是否来自区域结构分化、品类结构变化或趋势异常，以及对父指标商品订购渗透率的传导影响。可订门店数 = 订购门店数 / 渗透率。
- 区域、品类、趋势证据只用于解释可订门店数及其父指标，不扩展为经营总览报告。
- 客数渗透率、销售额、客单价、19点前链路指标、活跃供应商数不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 可订门店数 | 平均每个商品每天被设置为可订购的门店数（店日均口径），是商品订购渗透率计算的分母。统计期内按商品-日统计被设置为可订购的门店数。 |
| 商品订购渗透率 | 订购门店数 / 可订门店数，反映商品在各个门店的订购覆盖程度。 |
| 订购门店数 | 提交订购且订购数量大于0的门店数，作为渗透率计算的分子。 |

> 数据来源优先级：`qdm-cmr-cli report business indicators > area > category > trend`。所有数值必须在 CLI 返回结果中有据可查。
