> 说明：本模板用于经营分析下品效维度的售价价格指数(线上)（`priceIndex`）专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 售价价格指数(线上)是品效的一级子指标，反映售价水平与定价策略，属于品效维度下的盈利基础指标。
- 固定拆解链路：`品效 -> 售价价格指数(线上) -> 采购价格指数`。
- 本报告核心问题是判断售价价格指数当前水平是否低于品牌对标价格（阈值 100），同比环比变化方向及幅度，变化是否来自区域结构分化、品类结构变化或趋势异常，以及售价水平变化对品效的传导影响。
- 区域、品类、趋势证据只用于解释售价价格指数及其下钻链路，不扩展为经营总览报告。
- 客数渗透率、销售额、客数、客单价、19点前链路指标、活跃供应商数、三率综合得分不得作为本报告主指标行。
- 品效只用于父级传导分析，采购价格指数只用于子级传导分析，均不能替代售价价格指数主指标。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 十、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 售价价格指数(线上) | 钱大妈商品B价策略的最大价格跟各品牌对应商品的最大价格的比值，反映售价水平与品牌对标价格的竞争力。低于 100 表示售价低于对标价格，属于品效维度下的盈利基础指标，是品效的一级驱动因子。 |
| 品效 | 平均每个动销商品的销售额贡献（店日均销售额 / 店日均销售sku数），反映商品经营效率与盈利水平的核心指标。售价价格指数是其一级子指标。 |
| 采购价格指数 | 钱大妈商品采购成本与竞品商品采购成本的比值，反映采购成本端的竞争力水平。作为售价价格指数的子指标，通过成本端传导影响售价价格指数。 |

> 数据来源优先级：`qdm-cmr-cli report business indicators > area > category > trend`。所有数值必须在 CLI 返回结果中有据可查。
