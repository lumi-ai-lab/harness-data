# 采购价格指数指标分析报告模板

> 说明：本模板用于经营分析下品效树中的采购价格指数专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 采购价格指数是售价价格指数(线上)的叶子子指标，反映采购成本对经营效率的影响，属于定价与折扣策略类指标。
- 固定拆解链路：`品效 -> 售价价格指数(线上) -> 采购价格指数`。
- 本报告核心问题是判断采购价格指数当前水平及其环比变化，采购成本变化对售价价格指数和盈利空间的传导影响，以及区域和品类维度的采购成本分化情况。
- 区域、品类、趋势证据只用于解释采购价格指数及其对上游指标的传导，不扩展为经营总览报告。
- 客数渗透率、销售额、客数、客单价、19点前链路指标、活跃供应商数、三率综合得分不得作为本报告主指标行。
- 售价价格指数(线上)只用于父级传导，品效只用于上级传导，不能替代采购价格指数主指标。
- 当前采购价格指数仅覆盖蔬菜品类（业务定义：对标真甜农服的蔬菜采购价价格指数），品类数据中仅蔬菜有有效值。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 采购价格指数 | 钱大妈商品采购价格与竞品商品采购价格的比值，当前对标真甜农服的蔬菜采购价，反映采购成本端的竞争力水平。无阈值配置，需结合售价价格指数综合判断采购成本合理性 |
| 售价价格指数(线上) | 钱大妈商品B价策略的最大价格跟各品牌对应商品的最大价格的比值，采购价格指数的父级指标，阈值 <100 |
| 品效 | 平均每个动销商品的销售额贡献，采购价格指数的上级传导指标 |
