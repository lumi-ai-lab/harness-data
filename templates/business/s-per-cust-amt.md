# 客单价指标分析报告模板

> 说明：本模板用于经营分析下客数渗透率树中的客单价专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`客数渗透率 -> 客单价 -> 19点前客单价 -> 19点前单均件数、19点前件单价`。
- 本报告核心问题是判断客单价变化来自单客贡献、早时段客单、件数或件单价中的哪类证据，并说明对客数渗透率和销售规模的影响。
- 区域、品类、趋势证据只用于解释客单价及其下游指标，不扩展为经营总览报告。
- 销售额和客数可在影响分析中用于父级传导说明，但不得作为本报告主指标行。
- 毛利、品效、供应商指标不得作为本报告指标行。
- 客单价及其下钻链路只能归入第三章（用户渗透维度深度拆解），禁止放入第四章（品效维度）和第五章（供应链维度）。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
