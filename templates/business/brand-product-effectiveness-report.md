# 品效下钻分析报告模板

> 说明：本模板用于经营分析下的品效专项下钻报告。所有数值、同比、环比、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 章节标题必须保持 1 到 10 的顺序。
- 固定拆解链路：`品效 -> 商品订购渗透率、定价毛利率、售价价格指数 -> 订购门店数、可订门店数、预期毛利率、出库折让率、时段折扣率、促销折扣率、损耗率、采购价格指数`。
- 只展示 CLI 返回的数据；缺失指标行直接省略。
- 诊断必须基于已返回数据，使用“现象 -> 影响 -> 推断”的逻辑，不把通用业务常识写成已发生事实。
- 区域、品类、趋势证据只用于解释品效及其下钻指标，不扩展为经营总览报告。

## 十、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 品效 | 综合反映商品经营效率与盈利水平的核心指标 |
| 商品订购渗透率 | 订购门店数与可订门店数之间的渗透关系，反映商品订购覆盖能力 |
| 订购门店数 | 发生商品订购行为的门店数量 |
| 可订门店数 | 当前具备商品订购条件的门店数量 |
| 定价毛利率 | 商品定价层面的毛利水平 |
| 预期毛利率 | 基于策略或计划口径形成的预期毛利水平 |
| 出库折让率 | 出库环节产生的折让比例，反映履约折让对品效的影响 |
| 时段折扣率 | 特定时段折扣对销售价格和毛利的影响 |
| 促销折扣率 | 促销活动折扣对销售价格和毛利的影响 |
| 损耗率 | 商品损耗对经营效率和毛利的影响 |
| 售价价格指数 | 商品售价水平的指数化表达 |
| 采购价格指数 | 商品采购成本水平的指数化表达 |
