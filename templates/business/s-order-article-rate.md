> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 商品订购渗透率是品效的一级子指标，反映商品的门店覆盖程度与订购能力，隶属于商品订购渗透指标组。
- 固定拆解链路：`商品订购渗透率 -> 订购门店数、可订门店数`。
- 本报告核心问题是判断商品订购渗透率当前水平是否达标（阈值 >=80%），同比环比变化方向及幅度，变化是否来自区域结构分化、品类结构变化或趋势异常，以及渗透率变化对品效的传导影响。
- 区域、品类、趋势证据只用于解释商品订购渗透率及其下钻链路（订购门店数、可订门店数），不扩展为经营总览报告。
- 客数渗透率、销售额、客单价、19点前链路指标、全链路毛利指标、活跃供应商数、三率综合得分不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 七、核心问题诊断与根因分析

### 1. `<问题一：渗透率远未达到 >=80% 阈值>`

- 现象：商品订购渗透率当前值 26.91%，阈值 >=80%，差距约 53pp。所有品类和区域均未达标。冷藏加工最高 46.14%，猪肉最低 13.49%。
- 影响：较低的渗透率意味着大部分可订商品未被门店订购，商品覆盖和动销效率受限，直接拖累品效表现。
- 推断：`<基于 CLI 证据的有限根因判断：可能涉及商品配置策略、门店订购行为、品类结构差异等，CLI 趋势数据显示当前年份渗透率整体低于去年同期约 2-3pp，说明覆盖能力存在系统性下降>`

### 2. `<问题二：区域间渗透率分化明显，华东双降风险>`

- 现象：运营直管 32.41% vs 华东 22.92%，差距约 9.49pp。华东同环比均为负（yoy -0.32pp, mom -0.23pp），是唯一双降区域。
- 影响：华东区域渗透率持续下滑，且其作为主要区域对全国渗透率有较大拖累。
- 推断：`<基于 CLI 证据的有限根因判断：华东区域可能面临门店订购意愿下降或可订商品配置不匹配的问题>`

### 3. `<问题三：品类结构性短板突出，猪肉渗透率极低>`

- 现象：猪肉渗透率仅 13.49%，水果 22.64%、水产 23.27% 也偏低于均值 26.91%。蔬菜同比改善明显（+2.10pp）但绝对值仍仅 44.14%。品类间差距达 32.65pp。
- 影响：猪肉等低渗透品类拖累全国平均渗透率，结构不均衡严重。
- 推断：`<基于 CLI 证据的有限根因判断：猪肉等品类渗透率极低可能与商品标准化程度、订购门槛、门店需求匹配度有关>`

## 十、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 品效 | 平均每个动销商品的销售额贡献（店日均销售额 / 店日均销售 sku 数），反映商品经营效率与盈利水平的核心指标。商品订购渗透率是其一级子指标。 |
| 商品订购渗透率 | 每个商品的门店订购占比情况，衡量商品的门店覆盖程度。反映了可订商品中被门店实际订购的比例，是品效的一级驱动因子。统计逻辑：每个商品的门店订购占比情况。阈值 >=80%。 |
| 订购门店数 | 提交订购且订购数量大于 0 的门店数，作为渗透率计算的分子。反映发生订购行为的门店范围。 |
| 可订门店数 | 平均每个商品每天根据被设置为可订购的门店数，作为渗透率计算的分母。反映可承接订单的门店范围。 |

> 数据来源优先级：`qdm-cmr-cli report business indicators > area > category > trend`。所有数值必须在 CLI 返回结果中有据可查。
