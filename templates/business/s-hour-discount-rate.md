# 时段折扣率指标分析报告模板

> 说明：本模板用于经营分析下品效维度中定价毛利率链路的时段折扣率（`hourDiscountRate`）专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 时段折扣率是定价毛利率的子指标，属于品效维度下的"定价与折扣策略"指标组，反映日清商品在清仓打折时段内的折扣力度对定价毛利率和品效的影响。
- 固定拆解链路：`品效 -> 定价毛利率 -> 时段折扣率`。时段折扣率是叶子指标，无进一步下钻。
- 阈值区间：BETWEEN 12.5% ~ 14.5%。低于 12.5% 说明清仓折扣力度不足，可能影响日清效率和库存周转；高于 14.5% 说明清仓折扣力度过大，直接压缩定价毛利率。
- 本报告核心问题是判断时段折扣率是否落在目标区间内，偏离区间的方向和幅度，折扣压力集中在哪些区域和品类，以及折扣率变化对父指标定价毛利率和祖父指标品效的传导影响。
- 品效和定价毛利率只作为父级链路传导，不上主指标行。预期毛利率、出库折让率、促销折扣率、损耗率可作为同链路补充背景，不上主指标行。
- 商品订购渗透率、售价价格指数、采购价格指数、客数渗透率、活跃供应商数、销售额、客数、客单价、19点前链路指标不得作为本报告主指标行。
- 区域、品类、趋势证据只用于解释时段折扣率，不扩展为经营总览报告。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 六、核心问题诊断与根因推断

### 1. `<问题一：全国时段折扣率低于阈值下限 12.5%>`

- 现象：当前值 12.08%，低于阈值下限（12.5%）0.42pp，未落入 BETWEEN 12.5%-14.5% 区间。环比下降 0.48pp，显示折扣率在进一步收窄。
- 影响：折扣力度不足可能导致日清商品库存积压和周转效率下降；但短期对定价毛利率（当前 36.37%，高于阈值上限 32%）形成正向支撑。
- 推断：`<基于 CLI 证据的有限根因判断：可能原因包括日清商品结构变化（高折扣品类占比下降）、清仓时段策略调整、或日清商品整体需求改善导致折扣需求减少>`

### 2. `<问题二：预制菜和冷藏加工品类时段折扣率大幅超出阈值上限>`

- 现象：预制菜时段折扣率 17.19%（超出上限 2.69pp），冷藏加工 15.85%（超出上限 1.35pp），两个品类同环比均走强。这两个品类的超额折扣拉高了全国均值。
- 影响：预制菜和冷藏加工的高折扣直接压低其定价毛利率，是定价毛利率结构中需要重点审视的品类。
- 推断：`<基于 CLI 证据的有限根因判断：预制菜和冷藏加工为短保日清商品，可能因保质期压力需要更大力度清仓折扣；或两个品类存在集中到货后的集中清仓行为>`

### 3. `<问题三：华东区域时段折扣率环比大幅下降 1.80pp>`

- 现象：华东时段折扣率从高位 17.20% 降至当前 15.40%，环比下降 1.80pp，下降幅度在所有区域中最大。但当前值仍超出阈值上限。
- 影响：华东折扣率快速回落对全国均值形成下拉力量，是环比下降 0.48pp 的主要贡献区域。
- 推断：`<基于 CLI 证据的有限根因判断：华东可能正在调整清仓折扣策略，从高位向阈值区间靠拢；需持续跟踪是否在阈值区间内企稳>`

### 7.5 附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 品效 | 平均每个动销商品的销售额贡献（店日均销售额 / 店日均销售sku数），是经营分析三大一级核心指标之一。 |
| 定价毛利率 | 商品定价层面的毛利水平，是品效的一级子指标，为时段折扣率的父指标。 |
| 时段折扣率 | 日清商品在清仓打折时段内产生的折扣金额占全天原价销售额的比例（时段折扣额 / 原价销售额），反映时段折扣对定价毛利率和品效的影响。valueUnit=3（需×100转为百分比）。 |
| 预期毛利率 | 基于策略或计划口径形成的预期毛利水平。 |
| 出库折让率 | 出库环节产生的折让比例，反映履约折让对品效的影响。 |
| 促销折扣率 | 促销活动折扣对销售价格和毛利的影响，与时段折扣率同为定价与折扣策略组指标。 |
| 损耗率 | 商品损耗对经营效率和毛利的影响，反映日清商品未售出的损耗成本。 |
