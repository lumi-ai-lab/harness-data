# 出库折让率指标分析报告模板

> 说明：本模板用于经营分析下品效树中定价毛利率链路的出库折让率专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`品效 -> 定价毛利率 -> 预期毛利率 -> 出库折让率`。
- 本报告核心问题是判断出库折让率是否突破控制目标，折让压力集中在哪些区域/品类/趋势点，并说明对预期毛利率、定价毛利率和品效的侵蚀影响。
- 品效、定价毛利率和预期毛利率只用于父级传导，不能替代当前指标。
- 区域、品类、趋势证据只用于解释出库折让率，不扩展为经营总览报告。
- 时段折扣率、促销折扣率、损耗率可作为同一父级链路的补充背景，不得作为本报告主指标行。
- 商品订购渗透率、售价价格指数、采购价格指数、客数渗透率、活跃供应商数不得作为本报告主指标行。
- 出库折让率固定归入品效定价毛利率拆解，明确归品效，不得放入供应链章节。即使指标 code 包含"scm"，也必须按品效口径处理。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
