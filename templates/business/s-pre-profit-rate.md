# 预期毛利率指标分析报告模板

> 说明：本模板用于经营分析下品效树中定价毛利率链路的预期毛利率专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`品效 -> 定价毛利率 -> 预期毛利率 -> 出库折让率`。
- 本报告核心问题是判断预期毛利率是否处于目标区间（BETWEEN 33.5-35.5），是否存在过高/过低偏离，并说明对定价毛利率和品效的传导影响。
- 定价毛利率和品效只用于父级传导，出库折让率用于下游影响解释，不替代当前指标。
- 区域、品类、趋势证据只用于解释预期毛利率结构分化和异常，不扩展为经营总览报告。
- 时段折扣率、促销折扣率、损耗率可作为同一父级链路的补充背景，不得替代本报告主指标。
- 商品订购渗透率、售价价格指数、采购价格指数、客数渗透率、活跃供应商数不得作为本报告主指标行。
- 出库折让率固定归入品效定价毛利率拆解，不得放入供应链章节。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 品效 | 平均每个动销商品的销售额贡献，预期毛利率所属的经营分析一级核心指标 |
| 定价毛利率 | 定价毛利额/理论销售额，反映不做促销和折让时的理论毛利水平，预期毛利率的父级指标 |
| 预期毛利率 | 门店预期销售毛利额/原价销售额，反映商品按预期售价销售的理论毛利水平 |
| 出库折让率 | 出库让利总额/(出库到店金额+出库让利总额)，反映出库环节让利对预期毛利率的侵蚀程度 |
