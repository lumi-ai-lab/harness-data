## 通用填充规则

- 三率综合得分是活跃供应商数的子指标，反映供应商履约质量的综合水平。
- 固定拆解链路：`活跃供应商数 -> 三率综合得分 -> 准确率、准点率、合格率`。
- 本报告核心问题是判断三率综合得分当前水平是否达标，同比环比变化方向及幅度，哪个子指标（准确率/准点率/合格率）是主要驱动或拖累因素，以及区域和品类间的质量分化情况。
- 区域、品类、趋势证据只用于解释三率综合得分及其子指标的变化，不扩展为经营总览报告。
- 销售额、客数、客单价、19点前链路指标、品效及其下钻指标、出库折让率不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 十一、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 活跃供应商数 | 当前周期内有实际供货行为的供应商数量，反映供应链合作广度与稳定性的总纲指标 |
| 三率综合得分 | 取准确率、准点率、合格率的平均值并转换为百分制（avg(准确率+准点率+合格率)*100），反映供应商履约质量的综合水平 |
| 准确率 | 供应商实际交付的货品与订单要求一致的比例，反映供应商订单执行准确程度 |
| 准点率 | 供应商在约定时间内完成交付的比例，反映供应商交付时效性 |
| 合格率 | 供应商交付货品符合质量标准/验收要求的比例，反映供应商货品质量水平 |
