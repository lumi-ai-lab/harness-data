# 售价价格指数指标分析报告模板

> 说明：本模板用于经营分析下品效树中的售价价格指数(线上)专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`品效 -> 售价价格指数(线上) -> 采购价格指数`。
- 本报告核心问题是判断线上售价价格指数变化来自售价竞争力变化、采购价格指数变化，还是区域/品类价格结构分化，并说明对品效、价格竞争力和毛利空间的影响。
- 区域、品类、趋势证据只用于解释售价价格指数及采购价格指数，不扩展为经营总览报告。
- 商品订购渗透率、定价毛利率可在影响分析中用于品效传导说明，但不得作为本报告主指标行。
- 客数渗透率、销售额、全链路毛利率、活跃供应商数不得作为本报告主指标行。
- CLI 返回 null、0 或异常跳点时，只能按 CLI 事实描述为数据异常或结构异常，不得自行修正、平滑或估算。
