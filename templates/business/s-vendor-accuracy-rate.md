# 准确率指标分析报告模板

> 说明：本模板用于经营分析下供应链维度准确率指标的专项分析报告。准确率是**叶子指标**（无子指标），属于履约质量三率指标组（准确率、准点率、合格率），三率汇总为三率综合得分（`threeRateScore`）。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 准确率反映供应商送货质量，是履约质量三率之一，与准点率（`vendorIntimeRate`）、合格率（`vendorQualificationRate`）共同影响三率综合得分。
- 固定拆解链路：`活跃供应商数 -> 三率综合得分 -> 准确率`（叶子指标，无子指标）。
- 本报告核心问题是判断准确率当前水平是否达到 99% 阈值，同比环比变化方向及幅度，变化是否来自区域分化或品类结构差异，及准确率波动对三率综合得分的拖累程度。
- 区域、品类、趋势证据只用于解释准确率在供应链维度的表现，不扩展为经营总览报告。
- 销售额、客数、客单价、19点前链路指标、品效不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 十、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 供应商准确率 | 供应商送货数量符合入库标准的次数占总送货次数的比例（供应商准确次数 / 供应商送货次数），反映供应商送货质量的履约指标 |
| 三率综合得分 | 准确率、准点率、合格率的加权综合评分，反映供应商履约质量的整体水平 |
| 准点率 | 供应商按时送达的次数占总送货次数的比例 |
| 合格率 | 供应商送货质量检验合格的次数占总送货次数的比例 |
| 活跃供应商数 | 当前周期内有发生采购交易的供应商数量 |
