# 准点率指标分析报告模板

> 说明：本模板用于经营分析下供应链维度的准点率指标专项分析报告。准点率是叶子指标，无下级子指标。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 准点率是经营分析供应链维度履约质量三率指标组的叶子指标，反映供应商按时送货履约能力。
- 固定拆解链路：`活跃供应商数 -> 三率综合得分 -> 准点率`（叶子指标，无下级子指标）。
- 本报告核心问题是判断准点率当前水平是否达标（阈值 >= 99），同比环比变化方向及幅度，变化是否来自区域结构分化或品类结构分化，以及准点率变化对三率综合得分的贡献和影响。
- 区域、品类、趋势证据只用于解释准点率及其波动原因，不扩展为经营总览报告。
- 销售额、客数、客单价、19点前链路指标、品效及其子指标不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 准点率 | 供应商按时送货到仓库的次数占总送货次数的比例（供应商准点次数 / 供应商送货次数），反映供应商按时履约能力 |
| 三率综合得分 | 履约质量三率（准点率、准确率、合格率）的综合评分，反映供应链整体履约质量 |
| 准确率 | 供应商送货数量准确率，与准点率同属三率指标组 |
| 合格率 | 供应商送货质量合格率，与准点率同属三率指标组 |
| 活跃供应商数 | 报告周期内有送货记录的供应商数量，供应链维度的流量入口指标 |
