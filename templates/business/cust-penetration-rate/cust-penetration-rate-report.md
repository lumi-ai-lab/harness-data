> 说明：本模板用于经营分析下的客数渗透率专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`客数渗透率 -> 销售额、客数、客单价、全链路毛利率、全链路毛利额 -> 19点前链路、门店毛利、供应链毛利`。
- 只展示 CLI 返回的数据；缺失指标行直接省略。
- 本报告核心问题是判断客数渗透率变化对规模、转化、客单、毛利质量的影响，并定位主要驱动或拖累。
- 诊断必须使用“现象 -> 影响 -> 推断 -> 行动”的逻辑；CLI 只支持趋势或结构异常时，只能写“可能”“倾向于”，不得写成已确认事实。
- 区域、品类、趋势证据只用于解释客数渗透率及其树内指标，不扩展为经营总览报告。
- 品效、活跃供应商数及其下游指标不得作为本报告指标行；仅当 CLI 证据明确需要对比父级经营结果时，才可在影响分析中一句话引用。
