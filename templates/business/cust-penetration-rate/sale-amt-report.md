# 销售额指标分析报告模板

> 说明：本模板用于经营分析下客数渗透率树中的销售额专项报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`客数渗透率 -> 销售额 -> 19点前销售占比 -> 19点前销售重量、订单满足率`。
- 本报告核心问题是判断销售额变化来自规模结果、早时段销售承接、销售重量或订单满足约束中的哪类证据，并说明对客数渗透率的影响。
- 区域、品类、趋势证据只用于解释销售额及其下游指标，不扩展为经营总览报告。
- 客数、客单价、全链路毛利指标可在影响分析中用于父级传导说明，但不得作为本报告的主指标行。
- 品效、活跃供应商数及其下游指标不得作为本报告指标行。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写“可能”“倾向于”。
