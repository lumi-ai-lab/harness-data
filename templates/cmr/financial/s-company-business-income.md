## 通用填充规则

- 公司营业收入是 EBITDA 的二级子指标（showTable），反映公司整体收入的规模和结构。
- 固定拆解链路：`EBITDA -> 公司营业收入 -> 供应链收入(财务)、直营店收入、品牌管理&加盟费、其他业务收支净额`。
- 本报告核心问题是判断公司营业收入当前水平，同比环比变化方向及幅度，变化主要来自供应链、直营、加盟费还是其他业务，各收入来源的占比结构是否健康。
- 公司报表无品类维度，不分析品类结构。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 公司营业收入 | -加盟费用收入+供应链收入+直营门店收入+品牌使用费收入-直营门店成本+职能部门收入+（-其他收入-其他支出），反映公司整体收入规模 |
| 供应链收入(财务) | 公司财务口径下的供应链业务收入，是公司营业收入的组成部分 |
| 直营店收入 | 公司直营门店产生的业务收入，是公司营业收入的组成部分 |
| 品牌管理&加盟费 | 品牌使用费+加盟费收入，反映品牌和加盟体系的变现能力 |
| 其他业务收支净额 | 除供应链、直营、加盟费以外的其他业务收入与支出的净额 |
| 公司毛利额 | 公司营业收入减去对应成本后的毛利金额，在EBITDA链路中与公司营业收入并列 |
| EBITDA | 税息前利润 = 公司其他收入+门店业务毛利-费用总额-折旧及摊销 |
