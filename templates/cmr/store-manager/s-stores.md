# 营业门店数分析报告模板

> 说明：本模板用于门店管理下的营业门店数指标专项分析报告。所有数值、同比、环比、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 营业门店数是门店管理三大一级核心指标之一，反映门店网络规模与营业状态。
- 固定拆解链路：`营业门店数 -> 净增门店数、存量门店数、停业门店数 -> 开店数、闭店数 -> 待开业门店数、停业超30天门店数`。
- 本报告核心问题是判断营业门店数当前水平是否稳定，同比环比变化方向及幅度，变化是否来自区域结构分化或趋势异常，以及门店规模变化对整体经营网络的影响。
- 区域、趋势证据只用于解释营业门店数及其下钻链路，不扩展为经营总览报告。
- 销售额、客数、客单价、品效、19点前链路指标、活跃供应商数、三率综合得分不得作为本报告主指标行。
- 品类数据不得放入本报告任何章节（门店管理域不涉及品类维度）。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 十、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 营业门店数 | 当前处于正常营业状态的门店总数，反映门店网络规模与营业状态的一级核心指标 |
| 净增门店数 | 开店数减去闭店数，反映门店规模的净变动方向 |
| 存量门店数 | 持续维持营业状态的稳定门店数量，反映门店网络的基本盘 |
| 停业门店数 | 当前处于停业状态的门店数量，反映门店网络的异常风险 |
| 开店数 | 报告期内完成开业流程并正式营业的门店数量，反映门店扩张速度 |
| 闭店数 | 报告期内完成闭店流程的门店数量，反映门店收缩程度 |
| 待开业门店数 | 已批准筹建但尚未正式营业的门店数量，反映门店筹建管道储备 |
| 停业超30天门店数 | 停业时间超过30天的门店数量，反映长期停业风险 |
