# 盈亏平衡点指标分析报告模板

> 说明：本模板用于门店管理下的盈亏平衡点指标专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 盈亏平衡点是门店盈利与运营效率维度下的二级指标，归属于门店净利润（`netProfit`）拆解链路。
- 固定拆解链路：`门店净利润 -> 盈亏平衡点 -> 损耗率、员工工资、租金和物业管理费、店铺水电费、门店其他支出`。
- 本报告核心问题是判断盈亏平衡点当前水平是否达标（阈值 LE 2000），同比环比变化方向及幅度，变化是否来自区域成本结构分化或趋势异常，以及盈亏平衡点变化对门店盈利门槛的整体影响。
- 区域、趋势证据只用于解释盈亏平衡点及其下钻链路，不扩展为门店管理总览报告。
- 品类口径固定为全品类，不做品类下钻，不输出品类排名、品类拖累或品类贡献。
- 营业门店数、开店数、闭店数等门店规模指标不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 盈亏平衡点 | 门店达到盈亏平衡所需的最低销售额或收入水平，反映单店盈利门槛和成本压力。阈值：<= 2000 万元 |
| 门店净利润 | 门店总收入减去门店总成本后的净利润，反映门店整体盈利水平 |
| 损耗率 | 商品损耗对经营成本和盈亏平衡点的影响比例 |
| 员工工资 | 门店员工薪酬支出，是固定成本的主要构成之一 |
| 租金和物业管理费 | 门店场地租金及物业管理费用，是固定成本的核心构成 |
| 店铺水电费 | 门店日常经营产生的水电费用，反映经营成本变化 |
| 门店其他支出 | 门店除工资、租金、水电以外的其他经营支出 |
