# 停业门店数指标分析报告模板

> 说明：本模板用于门店管理下的停业门店数指标专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 停业门店数是门店规模与健康度维度下的叶子指标，归属于营业门店数（`stores`）拆解链路。
- 固定拆解链路：`营业门店数 -> 停业门店数`。
- 本报告核心问题是判断停业门店数的当前水平与短期停业风险，同比环比变化方向及幅度，变化是否来自区域结构分化或趋势异常，以及停业变化对门店运营健康度的整体影响。
- 区域、趋势证据只用于解释停业门店数的表现，不扩展为门店管理总览报告。
- 品类口径固定为全品类，不做品类下钻，不输出品类排名、品类拖累或品类贡献。
- 门店净利润、盈亏平衡点、坪效、人效等盈利与运营效率指标不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
