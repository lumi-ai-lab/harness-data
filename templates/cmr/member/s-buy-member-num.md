# 消费会员数指标分析报告模板

> 说明：本模板用于用户运营分析下的消费会员数指标专项分析报告。所有数值、同比、环比、区域排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 消费会员数是会员价值与复购转化维度下的叶子指标，反映会员消费基础盘，是会员复购率的分母。
- 父指标为会员复购率（`memberRepurchaseNoDifferenceRate`），固定链路：`会员复购率 -> 消费会员数`。
- 本报告核心问题是判断消费会员数当前规模及变化方向，区域结构分化是否合理，以及消费会员基础盘是否在扩大。
- 区域和趋势证据只用于解释消费会员数的结构分化和异常，不扩展为用户经营总览报告。
- 用户报表不支持品类过滤，不输出品类排名、品类拖累或品类贡献。
- 活跃用户数、新消费用户数、VIP 分层会员数、休眠/流失指标归入第三章，不得放入本报告。
- 社群用户数、官媒用户数、抖音用户数、可触达用户数、会员数归入第五章，不得放入本报告。
- 会员销售占比、交叉会员数、线上/线下消费会员数作为同维度参照，不替代消费会员数主指标。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
- 消费会员数 `threshold` 为 null，无预设阈值。
