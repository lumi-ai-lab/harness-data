# 复购会员消费频次指标分析报告模板

> 说明：本模板用于用户运营分析下的复购会员消费频次指标专项分析报告。
>
> **重要提示**：当前所有数据接口均返回空值或零值。该指标仅在 CLI 返回有值时展示。CLI 无有效数据时，报告整体省略此指标。

## 通用填充规则

- 复购会员消费频次是会员价值与复购转化维度下的叶子指标，衡量复购会员的消费深度（平均消费次数）。
- 父指标为会员复购率（`memberRepurchaseNoDifferenceRate`），固定链路：`会员复购率 -> 复购会员消费频次`。
- 用户报表不支持品类过滤。
- 活跃用户数、VIP分层会员数等归入第三章，不得放入本报告。
- 社群用户数、官媒用户数等归入第五章，不得放入本报告。
- 该指标仅在 CLI 返回有值时展示；当前无有效数据，报告省略。

## 数据结构占位（CLI 返回有效数据时使用）

### 一、报告概述
### 二、核心结论
### 三、整体表现
### 四、区域表现拆解
### 五、父级链路分析
### 六、问题诊断
### 七、优化策略
### 八、附录

| 指标 | 核心定义 |
| :--- | :--- |
| 复购会员消费频次 | 复购会员在统计周期内的平均消费次数（复购会员总消费次数 / 复购会员数），衡量复购深度 |
| 会员复购率 | 复购会员数 / 会员数，衡量会员忠诚度的一级核心指标 |
| 复购会员数 | 统计周期内至少完成2次及以上消费的会员人数 |
