## 通用填充规则

- 本指标为叶子指标，无下钻子指标，不展示父子链路章节。
- 本报告核心问题是判断休眠会员的挽回效果，分析挽回率变化趋势和区域差异。
- 用户挽回率固定归入"用户规模与分层结构"维度（第三章），不得放入第四章（用户价值与复购转化）或第五章（用户触达与渠道效率）。
- 用户挽回率仅在 CLI 返回有值时展示。当 CLI 返回值为 null 或全为 0 时，整个报告省略，不保留任何占位符。
- 区域、趋势证据只用于解释用户挽回率的表现，不扩展为用户总览报告。
- 用户报表不支持品类过滤，报告中不涉及品类维度分析。
- CLI 返回 null 或缺失区域时，只能按 CLI 事实描述为数据缺口，不得自行补数。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
