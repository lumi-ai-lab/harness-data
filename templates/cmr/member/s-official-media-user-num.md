# 官媒用户数指标分析报告模板

> 说明：本模板用于用户运营分析下的官媒用户数指标专项分析报告。所有数值、趋势异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。
>
> **重要提示**：该指标仅在 CLI 返回有值时展示。当前 `indicators` 子命令不返回该指标值，诊断需依赖 `trend` 子命令数据。

## 通用填充规则

- 官媒用户数是用户触达与渠道效率维度下的叶子指标，反映微信公众号粉丝覆盖能力。
- 父指标为可触达用户数（`reachMemberNum`），固定链路：`可触达用户数 -> 官媒用户数`。
- 本报告核心问题是判断官媒用户数当前规模及增长趋势，公众号粉丝是否保持健康增长。
- 趋势证据只用于解释官媒用户数的增长轨迹和异常，不扩展为用户经营总览报告。
- 用户报表不支持品类过滤，不输出品类排名、品类拖累或品类贡献。
- 当前区域数据不可用，不做区域拆解。
- 活跃用户数、新消费用户数、VIP 分层会员数、休眠/流失指标归入第三章，不得放入本报告。
- 会员复购率、消费会员数、复购会员数、复购会员消费频次、会员销售占比等归入第四章，不得放入本报告。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势异常时，只能写"可能""倾向于"。
- 官媒用户数 `threshold` 为 null，无预设阈值。

## 九、数据可用性说明

- 当前 `indicators` 子命令不返回官媒用户数指标值，诊断需依赖 `trend` 子命令。
- 当前 `area` 子命令返回空数据，不支持区域下钻。
- 报告遵循"指标配置存在但 CLI 没有返回值，不等于指标值为 0；最终报告应省略无值指标"原则。
- 如果 trend 子命令也返回空数据，本报告整体省略。
