# 用户运营深度报告模板

> 说明：本模板固定章节、表达风格、小节结构和指标归属。所有数值、同比、环比、排名、阈值、诊断事实必须来自 CLI 输出。
> 适用问题：用户询问“昨天的用户运营情况”“会员表现怎么样”等用户/会员运营类问题。

## 通用填充规则

- 章节标题必须保持 1 到 9 的顺序，三大拆解维度固定为：用户规模与分层结构、会员价值与复购转化、用户触达与渠道效率。
- 章节、指标归属、指标组和表格结构优先级高于模型自由组织。
- 区域口径按用户指定区域填充；若用户未指定区域，固定填充为全国（不含港澳）。
- 用户报表不支持品类过滤；若用户提到全品类，品类口径填充为用户报表默认全口径，不得声称 CLI 已传入品类筛选。
- 只展示 CLI 返回的数据；没有返回的指标行直接省略。
- 某个指标组内没有任何 CLI 返回指标时，可以省略该指标组。
- 额外指标只有在能解释关键用户运营现象时才补充，并放入语义最匹配的小节。
- 诊断语言保持“表现 -> 诊断”；关键问题与根因分析中必须体现“现象 -> 影响 -> 推断”。

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 活跃用户数 | 一定周期内有消费行为的用户总数，反映用户整体规模 |
| 会员复购率 | 产生复购行为的会员数/消费会员数，反映会员消费粘性 |
| 会员销售占比 | 会员消费金额/整体销售金额，反映会员对销售的贡献度 |
| 可触达用户数 | 可通过渠道触达的用户总数，反映用户触达基础池规模 |
| 新消费用户数 | 统计周期内首次产生消费行为的用户数量，反映新客获取能力 |
| 新客首客单价 | 新消费用户首次消费的平均客单价，反映新客首单消费质量 |
| 次月留存率 | 新用户在次月继续活跃或消费的比例，反映新客留存质量 |
| 休眠期会员数 | 进入休眠状态但尚未完全流失的会员数量，反映会员活跃衰退风险 |
| 流失期用户数 | 进入流失状态的用户数量，反映用户流失压力 |
| 用户挽回率 | 休眠/流失用户中被成功召回并产生消费的用户占比，反映用户召回能力 |
| 消费会员数 | 统计周期内产生消费行为的会员数量，反映会员消费基础盘 |
| 复购会员数 | 统计周期内产生复购行为的会员数量，反映会员复购规模 |
| 复购会员消费频次 | 复购会员在统计周期内的平均消费次数，反映复购深度 |
| 交叉会员数 | 同时在线上和线下等多个渠道产生消费或互动的会员数量，反映全渠道粘性 |
| 线上消费会员数 | 统计周期内在线上渠道产生消费行为的会员数量 |
| 线下消费会员数 | 统计周期内在线下渠道产生消费行为的会员数量 |
| 会员数 | 已注册或纳入会员体系的用户数量，反映会员基础池规模 |
| 社群用户数 | 进入社群渠道的用户数量，反映私域触达能力 |
| 官媒用户数 | 关注或沉淀在官方媒体渠道的用户数量，反映公域/品牌触达基础 |
| 抖音用户数 | 沉淀在抖音渠道的用户数量，反映内容平台触达能力 |
