> 说明：本模板用于经营分析下供应链维度合格率指标的专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 合格率是履约质量三率指标组的叶子指标，反映供应商送货质量的合规水平。
- 固定拆解链路：`活跃供应商数 -> 三率综合得分 -> 合格率`（叶子，无子指标）。
- 本报告核心问题是判断合格率当前水平是否达标（阈值 GE 99%），未达标时分析幅度和原因，以及合格率变化对三率综合得分的贡献。
- 区域、品类、趋势证据只用于解释合格率及其对三率综合得分的传导，不扩展为经营总览报告。
- 合格率固定归入供应链维度（第五章），不得放入第三章（用户渗透）或第四章（品效）。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
- 合格率为叶子指标，无子指标，不包含父子链路拆解章节。

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 合格率 | 供应商送货质量符合标准的次数占总送货次数的比例（供应商合格次数 / 供应商送货次数），反映供应商履约质量的核心指标 |
| 三率综合得分 | 履约质量三率（合格率、准点率、准确率）的综合加权评分，反映供应链履约质量的总体水平 |
| 准点率 | 供应商按时送货的比例，履约质量三率之一 |
| 准确率 | 供应商送货数量准确的次数占总送货次数的比例，履约质量三率之一 |
| 活跃供应商数 | 在统计周期内发生送货行为的供应商数量，是供应链维度的规模指标 |
