# 供应链毛利率指标分析报告模板

> 说明：本模板用于经营分析下客数渗透率树中的供应链毛利率专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`客数渗透率 -> 全链路毛利率 -> 供应链毛利率`。
- 本报告核心问题是判断供应链端毛利率水平是否达标，同比环比变化方向及幅度，变化是否来自区域结构分化、品类结构变化或趋势异常，以及供应链毛利率变化对全链路毛利率和客数渗透率的传导影响。
- 全链路毛利率和客数渗透率只用于父级传导，门店毛利率只作为同组补充，不替代当前主指标。
- 区域、品类、趋势证据只用于解释供应链毛利率结构分化和异常，不扩展为经营总览报告。
- 禁放：第四章（品效维度）、第五章（供应链维度）。虽名为供应链毛利率，但报告归入第三章用户渗透维度全链路盈利部分。
- 销售额、客数、客单价、19点前链路指标、品效维度指标、供应链三率、活跃供应商数、集采入库占比不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
- 供应链毛利率 `valueUnit: 3`，值为小数比率（如 0.10588 = 10.59%），同比环比 unit 为 3（百分点变化）。
- 供应链毛利率阈值 `compareValue1: 11.18`，`compareSymbol: "GT"`，表示需要 >11.18%。
