## 通用填充规则

- 客数渗透率是经营分析三大一级核心指标之一，反映用户覆盖与触达能力。
- 固定拆解链路：`客数渗透率 -> 销售额、客数、客单价、全链路毛利率、全链路毛利额`。
- 本报告核心问题是判断客数渗透率当前水平是否达标，同比环比变化方向及幅度，变化是否来自区域结构分化、品类结构变化或趋势异常，以及客数渗透率变化对用户规模与经营结果的整体影响。
- 区域、品类、趋势证据只用于解释客数渗透率及其下钻链路，不扩展为经营总览报告。
- 品效指标（定价毛利率、售价价格指数、预期毛利率、出库折让率等）、供应链指标（活跃供应商数、三率综合得分等）不得作为本报告主指标行。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 十、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 客数渗透率 | 到店的客流占门店300米半径范围覆盖的小区户数的占比（来客数 / 门店覆盖户数），反映用户覆盖与触达能力的核心指标；若门店复购户数为空则显示"--" |
| 销售额 | 门店销售商品的总金额（原价销售额减去日结相关优惠金额后，剩余的结算金额），反映经营结果 |
| 客数 | 每天消费的顾客订单数（按销售小票ID统计），反映用户规模；物料大分类订单数计为0 |
| 客单价 | 平均每笔订单的订单金额（销售额 / 来客数），反映单客价值与消费结构 |
| 全链路毛利率 | 全链路到店毛利额（不含税）占销售额的比例 = (供应链到店毛利额（不含税）+ 门店毛利额) / 销售额，反映整体经营效率 |
| 全链路毛利额 | 从商品采购入库到门店销售全流程产生的税前毛利 = 供应链到店毛利额（不含税）+ 门店毛利额，不包含非到店业务商品产生的毛利 |
