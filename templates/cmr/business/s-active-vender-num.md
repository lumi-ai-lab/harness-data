# 活跃供应商数指标分析报告模板

> 说明：本模板用于经营分析下的活跃供应商数指标专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 活跃供应商数是经营分析三大一级核心指标之一，反映供应链合作广度与稳定性。
- 固定拆解链路：`活跃供应商数 -> 集采入库占比、三率综合得分 -> 准确率、准点率、合格率`。
- 本报告核心问题是判断活跃供应商数当前水平是否达标，同比环比变化方向及幅度，变化是否来自区域结构分化、品类结构变化或趋势异常，以及活跃供应商数变化对供应链协同能力和履约质量的整体影响。
- 区域、品类、趋势证据只用于解释活跃供应商数及其下钻链路，不扩展为经营总览报告。
- 销售额、客数、客单价、19点前链路指标、品效、商品订购渗透率、定价毛利率、售价价格指数不得作为本报告主指标行。
- 出库折让率固定归品效维度，不得放入本报告供应链章节。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
- 活跃供应商数 `threshold` 为 null，无预设阈值。

## 十、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 活跃供应商数 | 统计周期内有入库金额的去重供应商数量（入库金额＞0），反映供应链合作广度与稳定性的核心指标 |
| 集采入库占比 | 集采渠道入库金额或数量占总入库的比例，反映集采集中度与入库协同程度 |
| 三率综合得分 | 准确率、准点率、合格率的综合质量评分，反映供应商履约质量的综合水平 |
| 准确率 | 供应商供货数量与订单数量的匹配准确程度 |
| 准点率 | 供应商在约定时间内完成交付的比率 |
| 合格率 | 供应商供应商品质量检验合格的比例 |
