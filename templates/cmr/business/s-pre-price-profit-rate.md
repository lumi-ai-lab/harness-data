# 定价毛利率指标分析报告模板

> 说明：本模板用于经营分析下品效维度的定价毛利率专项分析报告。所有数值、同比、环比、阈值、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 定价毛利率是品效的一级子指标，归入盈利基础指标组，反映商品定价层面的理论毛利水平。
- 父指标为品效（`brandProductEffectiveness`），固定拆解链路：`品效 -> 定价毛利率 -> 预期毛利率、出库折让率、时段折扣率、促销折扣率、损耗率`。
- 本报告核心问题是判断定价毛利率当前水平是否处于阈值区间（30%-32%），同比环比变化方向及幅度，变化是否来自预期毛利率变动、折扣率结构变化或损耗率异常，以及定价毛利率变化对品效和商品盈利基础的整体影响。
- 区域、品类、趋势证据只用于解释定价毛利率及其下钻链路，不扩展为经营总览报告。
- 第三章（用户渗透）和第五章（供应链）的主指标不得作为本报告的主指标行或关联指标呈现。
- 销售额、客数、客单价、19点前链路指标、活跃供应商数、三率综合得分不得作为本报告主指标行。
- 商品订购渗透率、售价价格指数、采购价格指数可在影响分析中用于品效传导说明，但不得作为本报告主指标行。
- 出库折让率固定归入品效定价毛利率拆解，不得放入供应链章节。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 十、附录：指标定义说明

| 指标 | code | 核心定义 | 统计逻辑 |
| :--- | :--- | :--- | :--- |
| 品效 | `brandProductEffectiveness` | 平均每个动销商品的销售额贡献，反映商品经营效率与盈利水平的核心指标 | 店日均销售额 / 店日均销售SKU数 |
| 定价毛利率 | `prePriceProfitRate` | 门店库存可售商品按照公司的价格策略进行正常销售，不做任何的促销和折让，产生的理论毛利额占理论销售收入的比例 | 定价毛利额 / 理论销售额 |
| 预期毛利率 | `preProfitRate` | 门店商品预期销售毛利额占原价销售额的比例 | 门店预期销售毛利额 / 原价销售额 |
| 出库折让率 | `scmPromotionTotalRate` | 出库让利总额占预期出库到店金额的占比 | 出库让利总额 / (出库到店金额 + 出库让利总额) |
| 时段折扣率 | `hourDiscountRate` | 日清商品在清仓打折时段内产生的折扣金额占全天原价销售额的比例 | 时段折扣额 / 原价销售额 |
| 促销折扣率 | `promotionDiscountRate` | 促销折扣额占原价销售额的比例 | 促销折扣额 / 原价销售额 |
| 损耗率 | `lostRate` | 由于各种原因导致的门店商品价值减少占门店进货额和期初期末库存差额的比例 | 损耗额 / (进货额 + 期初库存金额 - 期末库存金额) |
