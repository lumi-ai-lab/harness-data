## 通用填充规则

- 19点前销售占比是销售额的子指标，属于19点前链路指标组，反映清仓时段前的用户行为链路转化效率。
- 固定拆解链路：`19点前销售占比 -> 19点前销售重量、订单满足率`。
- 本报告核心问题是判断19点前销售占比当前水平是否达标，同比环比变化方向及幅度，变化是否来自区域结构分化、品类结构变化或趋势异常，以及19点前销售占比变化对销售额与前段转化的整体影响。
- 区域、品类、趋势证据只用于解释19点前销售占比及其下钻链路，不扩展为经营总览报告。
- 19点前链路指标归用户渗透维度，品效指标、供应链指标不得作为本报告主指标行。订单满足率归用户行为链路，不得放入供应链章节。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。

## 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 19点前销售占比 | 清仓时段前销售额占全天销售额的比例（门店19点前销售额 / 销售额），反映用户行为链路的前段转化效率 |
| 19点前销售重量 | 清仓时段前售出商品的总重量（19点前销售数量 * 商品资料表的商品单位重量），用于判断白天前段转化强弱 |
| 订单满足率 | 满足分拣标准的订单数占门店订购订单数的比例（订单满足次数 / 订购订单次数），归用户行为链路 |
