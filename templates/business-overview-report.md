## 通用填充规则

- 章节标题必须保持 1 到 9 的顺序，三大拆解维度固定为：用户渗透、品效、供应链。
- 章节、指标归属、指标组和表格结构优先级高于模型自由组织。
- 只展示 CLI 返回的数据；没有返回的指标行直接省略。
- 某个指标组内没有任何 CLI 返回指标时，可以省略该指标组。
- 额外指标只有在能解释关键经营现象时才补充，并放入语义最匹配的小节。
- 诊断语言保持“表现 -> 诊断”；关键问题与根因分析中必须体现“现象 -> 影响 -> 推断”。

## 九、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 客数渗透率 | 下单用户数/目标用户数，反映用户覆盖能力 |

| 全链路毛利率 | （销售额-全链路成本）/销售额，反映整体盈利水平 |
| 三率综合得分 | 准确率、准点率、合格率的综合评分，反映供应商履约质量 |
