# 会员复购率指标分析报告模板

> 说明：本模板用于用户运营分析下的会员复购率指标专项分析报告。所有数值、同比、环比、区域排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。
>
> **重要提示**：当前所有数据接口（`indicators`、`area`、`trend`）均返回空值或零值。该指标仅在 CLI 返回有值时展示。CLI 无有效数据时，报告整体省略此指标。

## 通用填充规则

- 会员复购率是会员价值与复购转化维度的一级核心指标，反映会员粘性与消费忠诚度。
- 固定拆解链路：`会员复购率 -> 复购会员数、消费会员数、复购会员消费频次`。
- 本报告核心问题是判断会员复购率当前水平及变化方向，分子（复购会员数）和分母（消费会员数）的结构性变化，以及复购深度（消费频次）趋势。
- 区域和趋势证据只用于解释会员复购率的指标分析，不扩展为用户经营总览报告。
- 用户报表不支持品类过滤，不输出品类排名、品类拖累或品类贡献。
- 活跃用户数、新消费用户数、VIP 分层会员数、休眠/流失指标归入第三章，不得放入本报告。
- 社群用户数、官媒用户数、抖音用户数、可触达用户数、会员数归入第五章，不得放入本报告。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
- 会员复购率 `threshold` 为 null，无预设阈值。
- 该指标仅在 CLI 返回有值时展示；当前无有效数据，报告省略。

## 十、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 会员复购率 | 复购会员数 / 会员数，衡量会员忠诚度的一级核心指标 |

| 会员数 | 累计注册会员总数 |
