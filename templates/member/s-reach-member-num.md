# 可触达用户数指标分析报告模板

> 说明：本模板用于用户报表下活跃用户数树中的可触达用户数专项报告。所有数值、同比、环比、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 固定拆解链路：`可触达用户数 -> 会员数、社群用户数、官媒用户数、抖音用户数`。
- 本报告核心问题是判断可触达用户规模变化趋势、各渠道触达结构及转化效率，并说明对用户触达基础设施和渠道效率的影响。
- 可触达用户数跨维度归属：第三章（用户规模与分层结构）和第五章（用户触达与渠道效率），禁止放入第四章（用户价值与复购转化）。
- 区域数据当前为 null（rows 为空），报告中不得编造区域维度分析。
- 用户报表不支持品类过滤，报告中不涉及品类维度分析。
- CLI 返回 null 或缺失数据时，只能按 CLI 事实描述为数据缺口，不得自行补数。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
