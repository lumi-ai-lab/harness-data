# 流失期用户数指标分析报告模板

> 说明：本模板用于用户报表下活跃用户数树中的流失期用户数专项报告。所有数值、同比、环比、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 本指标为叶子指标，无下钻子指标，不展示父子链路章节。
- 本报告核心问题是判断流失用户规模变化趋势、区域集中度，并说明对用户资产健康度和会员生命周期管理的影响。
- 流失期用户数固定归入"用户规模与分层结构"维度（第三章），不得放入第四章（用户价值与复购转化）或第五章（用户触达与渠道效率）。
- 区域、趋势证据只用于解释流失期用户数的表现，不扩展为用户总览报告。
- 用户报表不支持品类过滤，报告中不涉及品类维度分析。
- CLI 返回 null 或缺失区域时，只能按 CLI 事实描述为数据缺口，不得自行补数。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
