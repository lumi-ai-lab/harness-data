# 会员数指标分析报告模板

> 说明：本模板用于用户运营下的会员数专项分析报告。所有数值、同比、环比、排名、异常点、诊断事实和根因判断必须来自 CLI 输出。
> CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据或静态示例值。

## 通用填充规则

- 会员数是可触达用户数（`reachMemberNum`）的子指标，为叶子指标，反映小程序会员规模和私域用户资产。
- 所属维度：用户触达与渠道效率（第五章）。
- 本报告核心问题是判断会员数当前规模与增长态势，同比环比变化方向及幅度，以及区域结构分化对会员数的影响。
- 会员数无阈值配置，不做达标判断。
- 禁止放入第三章（用户规模与分层结构）和第四章（会员价值与复购转化）。
- 用户报表不支持品类维度，不输出品类排名、品类拖累或品类贡献。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑。
- 根因必须受 CLI 证据约束。

## 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 会员数 | 钱大妈小程序中的会员数量（会员id去重计数），反映小程序会员规模和私域用户资产的关键指标 |
| 可触达用户数 | 可被触达的用户总量，是会员数的父指标，反映可运营用户基础池 |
| 社群用户数 | 社群渠道中的用户数量，反映私域触达能力 |
| 官媒用户数 | 官方媒体渠道中的用户数量，反映官媒触达基础 |
| 抖音用户数 | 抖音平台中的用户数量，反映内容平台触达基础 |
