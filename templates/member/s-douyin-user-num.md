# 抖音用户数指标分析报告模板

> 说明：本模板用于用户运营分析下的抖音用户数指标专项分析报告。
>
> **重要提示**：当前所有数据接口（`indicators`、`area`、`trend`）均返回空值或零值。该指标仅在 CLI 返回有值时展示。CLI 无有效数据时，报告整体省略此指标。

## 通用填充规则

- 抖音用户数是用户触达与渠道效率维度下的叶子指标，反映抖音平台粉丝覆盖能力。
- 父指标为可触达用户数（`reachMemberNum`），固定链路：`可触达用户数 -> 抖音用户数`。
- 用户报表不支持品类过滤，不输出品类排名、品类拖累或品类贡献。
- 活跃用户数、VIP 分层会员数、休眠/流失指标归入第三章，不得放入本报告。
- 会员复购率、消费会员数、复购会员数、会员销售占比等归入第四章，不得放入本报告。
- 该指标仅在 CLI 返回有值时展示；当前所有接口均返回空值/零值，报告生成时应省略此指标。
- 所有数值必须来自 CLI 输出；CLI 未返回有效值时，直接省略指标行。

## 数据结构占位

当 CLI 返回有效数据时，报告应包含以下章节结构。当前无数据，以下仅为参考框架：

### 一、报告概述（无数据时省略）
### 二、核心结论（无数据时省略）
### 三、整体表现（无数据时省略）
### 四、区域表现拆解（无数据时省略）
### 五、父级链路分析（无数据时省略）
### 六、问题诊断（无数据时省略）
### 七、优化策略（无数据时省略）
### 八、附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| 抖音用户数 | 抖音钱大妈QDM的粉丝数量，反映内容平台触达基础 |
| 可触达用户数 | 可通过企业微信、社群、公众号等渠道触达的用户总量，反映可运营用户基础池 |
