# 财务核心指标深度报告模板

> 说明：本模板由 `templates/financial-demo.md` 提炼而来，固定章节、表达风格、小节结构和指标归属。所有数值、同比、环比、排名、阈值、诊断事实必须来自 CLI 输出。
> 适用问题：用户询问“财务报表”“公司财务情况”“盈利情况”“EBITDA 表现”等财务/公司报表类问题。
> 生成报告时必须遵守本模板中的指标归属、缺失省略、单位展示和禁放规则。

## 通用填充规则

- 章节标题必须保持 1 到 9 的顺序，三大拆解维度固定为：盈利核心指标、收入结构与毛利贡献、费用管控与成本效率。
- 章节、指标归属、指标组和表格结构优先级高于模型自由组织。
- 公司/财务报表只支持周、月时间粒度；用户询问昨天、今天或具体日期时，必须按所在 ISO 周填充，并在报告概述说明“不支持日维度，已按所在周统计”。
- 区域口径按用户指定区域填充；若用户未指定区域，填充为 CLI 默认全国口径。
- 品类维度不可选，品类口径固定填充为全品类。
- 只展示 CLI 返回的数据；没有返回的指标行直接省略。
- 某个指标组内没有任何 CLI 返回指标时，可以省略该指标组。
- 额外指标只有在能解释关键财务现象时才补充，并放入语义最匹配的小节。
- 诊断语言保持“表现 -> 诊断”；关键问题与根因分析中必须体现“现象 -> 影响 -> 推断”。
- 金额单位按 CLI 返回值和 `valueUnit`/`zhCNUnit` 展示，不自行换算；若必须换算，需同时保留原始单位并说明换算来源。

## 附录：指标定义说明

| 指标 | 核心定义 |
| :--- | :--- |
| EBITDA | 息税折旧摊销前利润，反映企业核心经营业务的盈利和现金流创造能力 |
| 公司营业收入 | 企业各业务板块收入合计，反映整体业务规模 |
| 公司毛利额 | 营业收入扣除直接成本后的利润，反映基础盈利水平 |
| 费率/额 | 期间费用率及期间费用金额，反映费用管控效率与成本压力 |
| 宣传促销补贴费率/额 | 宣传促销与补贴相关费用占收入比例及金额，反映市场投入和补贴强度 |
