# 19点前复购率指标报告规则

该文件用于经营分析下客数渗透率树中的19点前复购率专项报告。取数固定使用 `qdm-cmr-cli report business`，指标固定为 `19点前复购率` 或 `bf19MemberRepurchaseRate`。

## 一、基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 19点前滚动7天会员复购率 |
| 指标英文 code | `bf19MemberRepurchaseRate` |
| 业务定义 | T天购买b分类的会员中，在T+1~T+7天19点前内复购同分类的比例（若需统计全品类，则不考虑商品分类） |
| 统计逻辑 | 19点前滚动7天复购会员数 / 消费会员数 |
| 业务环节 | 销售经营 |
| 指标ID | 1906611307212607489 |

## 二、指标位置

- 当前指标 code：`bf19MemberRepurchaseRate`
- 当前指标中文名：19点前滚动7天会员复购率
- 上级指标：客数渗透率 `custPenetrationRate`、客数 `custNum`
- 父指标：19点前客数 `bf19CustNum`
- 同组指标：19点前PI值 `bf19CategoryStoreCustRate`
- 叶子指标（无子指标）
- 指标组：19点前链路

固定拆解链路：

`客数渗透率 -> 客数 -> 19点前客数 -> 19点前复购率`

## 三、指标归属

| 指标 | 所属链路 | 报告章节 | 禁止放入位置 |
| :--- | :--- | :--- | :--- |
| 客数渗透率 | 上级指标 | 父子链路与传导判断 | 作为19点前复购率主指标替代项 |
| 客数 | 上级指标 | 父子链路与传导判断 | 作为19点前复购率主指标替代项 |
| 19点前客数 | 父指标 | 父子链路与传导判断 | 作为19点前复购率主指标替代项 |
| 19点前复购率 | 当前指标 | 19点前复购率整体表现与趋势 | 品效、供应链专项章节 |
| 19点前PI值 | 同组指标 | 同组触达质量补充 | 不得替代复购判断 |

报告禁止放入第四章（品效维度）和第五章（供应链维度）。

## 四、允许解释链路

- 19点前复购率变化可解释为会员在19点前时段的复购活跃度变化，通过父级链路向19点前客数、客数和客数渗透率传导。
- 客数渗透率、客数和19点前客数只用于父级传导，不能替代19点前复购率主指标。
- 19点前PI值只作为同组触达质量补充，不得替代复购判断。
- 滚动7天复购率在单日快照中为0是正常现象（单日快照无法反映滚动窗口的复购行为），必须按CLI事实谨慎描述，不得自行解释为会员流失、系统异常或活动原因。
- 区域、品类、趋势证据可用于定位19点前复购率结构分化和异常。
- 19点前复购率无阈值配置，CLI未返回threshold字段，报告中不展示阈值。

## 五、禁放规则

- 销售额、19点前销售占比、19点前销售重量、订单满足率、客单价、毛利率、毛利额及其下游指标不得作为本报告主指标行。
- 品效、商品订购渗透率、定价毛利率、售价价格指数、活跃供应商数、供应商三率不得作为本报告指标行。
- 全链路毛利率、全链路毛利额、门店毛利率、门店毛利额、供应链毛利率、供应链毛利额不得作为本报告指标行。
- 19点前客单价、19点前单均件数、19点前件单价、19点前客单重量及其下游指标不得作为本报告主指标行。
- 出库折让率、时段折扣率、促销折扣率、损耗率、采购价格指数不得作为本报告指标行。
- 不得使用本地 demo、静态样例、经验估算或模板占位符替代 CLI 返回事实。
- CLI 未返回的指标行、区域、品类、趋势点直接省略。
- 根因必须受 CLI 证据约束，只有趋势或结构异常时只能写有限推断。

## 六、数据来源规则

- 所有数值、同比、环比、阈值、排名、异常和根因必须来自 CLI 输出。
- 必要来源为 `report business indicators`、`area`、`category`、`trend`。
- 若必要模块失败或 `inject-template` 未成功，不得生成最终报告。
- valueUnit=3 表示小数形式的比率，需乘以100转为百分比；同比/环比 unit=3 表示百分点变化（小数形式）。
- 19点前复购率在单日快照中的默认值为0，不得用趋势期均值或其他周期数据替代单日CLI返回值。
