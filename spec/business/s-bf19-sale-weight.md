# 19点前销售重量指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code bf19SaleWeight --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 19点前销售重量 |
| 指标英文 code | `bf19SaleWeight` |
| 业务定义 | 清仓时段前售出商品的总重量，按商品资料表的单位重量*数量换算 |
| 统计逻辑 | 19点前销售数量 * 商品资料表的商品单位重量 |
| 业务环节 | 销售经营 |

## 指标定位

- 19点前销售重量是19点前销售占比的子指标，属于19点前链路指标组。
- 所属维度：用户渗透维度。
- 报告章节：第三章 用户渗透维度深度拆解。
- 叶子指标，无下钻子指标。用于判断白天前段转化强弱。

## 下钻子指标

无。19点前销售重量为叶子指标。

## 边界与禁放规则

- 19点前链路指标归用户渗透维度，不得放入品效章节（第四章）或供应链章节（第五章）。
- 品效指标、供应链指标不得通过19点前重量交叉引用放入用户渗透章节。
- 区域、品类、趋势证据只能用于解释19点前销售重量及其对上层指标的贡献。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
