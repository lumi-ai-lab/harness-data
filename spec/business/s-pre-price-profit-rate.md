# 定价毛利率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code prePriceProfitRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 定价毛利率 |
| 指标英文 code | `prePriceProfitRate` |
| 业务定义 | 门店库存可售商品按照公司的价格策略进行正常销售，不做任何的促销和折让，产生的理论毛利额占理论销售收入的比例 |
| 统计逻辑 | 定价毛利额 / 理论销售额 |
| 业务环节 | 全链路 |

## 指标定位

- 定价毛利率是经营分析 `/report/2` 品效维度的一级子指标，归入盈利基础指标组。
- 所属维度：品效维度。
- 报告章节：第四章 品效维度深度拆解。
- 父指标为品效（`brandProductEffectiveness`）。
- 固定拆解链路：`品效 -> 定价毛利率 -> 预期毛利率、出库折让率、时段折扣率、促销折扣率、损耗率`。

## 边界与禁放规则

- 第三章（用户渗透）和第五章（供应链）的主指标不得放入定价毛利率章节作为主指标行或关联指标呈现。
- 销售额、客数、客单价、19点前链路指标不得放入定价毛利率章节作为主指标行。
- 准确率、准点率、合格率、三率综合得分、活跃供应商数不得放入定价毛利率章节。
- 商品订购渗透率、售价价格指数、采购价格指数可在影响分析中用于品效传导说明，但不得作为本指标的主指标行。
- 出库折让率固定归入品效定价毛利率拆解，不得放入供应链章节。
- 区域、品类、趋势证据只能用于解释定价毛利率及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
