# 客数渗透率指标报告规则

该文件用于经营分析下的客数渗透率专项报告。客数渗透率归属 `business` domain，取数固定使用 `qdm-cmr-cli report business`，指标固定为 `客数渗透率` 或 `custPenetrationRate`。

## 指标位置

- 当前指标 code：`custPenetrationRate`
- 当前指标中文名：客数渗透率
- 父指标：无，属于经营分析一级指标树根指标
- 子指标：销售额、客数、客单价、全链路毛利率、全链路毛利额

固定拆解链路：

`客数渗透率 -> 销售额、客数、客单价、全链路毛利率、全链路毛利额 -> 19点前销售占比、19点前销售重量、订单满足率、19点前客数、19点前PI值、19点前复购率、19点前客单价、19点前单均件数、19点前件单价、门店毛利率、供应链毛利率、门店毛利额、供应链毛利额`

## 允许解释链路

- 客数渗透率变化可解释为销售规模、客流规模、单客贡献、全链路毛利质量之间的传导结果。
- 19点前链路只用于解释销售额、客数、客单价的时段结构，不得扩展成独立经营总览。
- 门店毛利与供应链毛利只用于解释全链路毛利率或毛利额，不得把供应商三率、集采入库占比放入本报告。
- 区域、品类、趋势证据可用于定位客数渗透率的结构分化和异常，但不得替代指标树内的必要事实。

## 禁放规则

- 商品订购渗透率、订购门店数、可订门店数、定价毛利率、预期毛利率、出库折让率、时段折扣率、促销折扣率、损耗率、售价价格指数、采购价格指数不得作为客数渗透率报告指标行。
- 活跃供应商数、集采入库占比、三率综合得分、准确率、准点率、合格率不得作为客数渗透率报告指标行。
- 不得使用本地 demo、静态样例、经验估算或模板占位符替代 CLI 返回事实。
- CLI 未返回的指标行、区域、品类、趋势点直接省略，不补写缺失说明。
- 根因必须受 CLI 证据约束；只有趋势或结构异常时，只能写有限推断。

## 数据来源规则

- 所有数值、同比、环比、阈值、排名、异常和根因必须来自 CLI 输出。
- 必要来源为 `report business indicators`、`tree --values`、`tree --chart`、`area`、`category`、`trend`。
- 若必要模块失败或 `inject-template` 未成功，不得生成最终报告。
