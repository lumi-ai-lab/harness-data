# 三率综合得分指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code threeRateScore --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 三率综合得分 |
| 指标英文 code | `threeRateScore` |
| 业务定义 | 取准确率+准点率+合格率的平均值，并转换百分制 |
| 统计逻辑 | avg（准确率+准点率+合格率）*100 |
| 业务环节 | 供应链环节 |

## 指标定位

- 三率综合得分是经营分析 `/report/2` 中活跃供应商数的子指标，属于供应链维度的中间层指标。
- 所属维度：供应链维度。
- 所属指标组：供应商合作与集采指标。
- 报告章节：第五章 供应链维度深度拆解。
- 固定拆解链路：`活跃供应商数 -> 三率综合得分 -> 准确率、准点率、合格率`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 准确率 | `vendorAccuracyRate` | 履约质量三率指标 |
| 一级子指标 | 准点率 | `vendorIntimeRate` | 履约质量三率指标 |
| 一级子指标 | 合格率 | `vendorQualificationRate` | 履约质量三率指标 |

## 边界与禁放规则

- 三率综合得分及其子指标（准确率、准点率、合格率）固定归入供应链维度（第五章），不得放入用户渗透章节（第三章）和品效章节（第四章）。
- 销售额、客数、客单价、19点前链路指标、品效及其下钻指标均不得放入三率综合得分分析章节。
- 出库折让率固定归入品效维度，不得在三率综合得分章节中出现。
- 区域、品类、趋势证据只能用于解释三率综合得分及其子指标变化，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
