# 售价价格指数(线上)指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code priceIndex --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 售价价格指数(线上) |
| 指标英文 code | `priceIndex` |
| 业务定义 | 钱大妈商品B价策略的最大价格跟各品牌对应商品的最大价格的比值 |
| 统计逻辑 | 价格指数分子/价格指数分母 |
| 业务环节 | 价格管理 |

## 指标定位

- 售价价格指数(线上)是经营分析 `/report/2` 中品效（`brandProductEffectiveness`）的一级子指标。
- 所属维度：品效维度。
- 报告章节：第四章 品效维度深度拆解。
- 固定拆解链路：`品效 -> 售价价格指数(线上) -> 采购价格指数`。
- 所属指标组：盈利基础指标。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 二级子指标 | 采购价格指数 | `purchasePriceIndex` | 定价与折扣策略 |

## 边界与禁放规则

- 售价价格指数(线上)不得放入第三章（客数渗透率维度）、第五章（活跃供应商数维度）。
- 销售额、客数、客单价、19点前链路指标、全链路毛利率、门店毛利率、供应链毛利率、三率综合得分不得放入售价价格指数相关分析。
- 品效和采购价格指数只能用于父子链路传导分析，不得替代售价价格指数作为主指标行。
- 区域、品类、趋势证据只能用于解释售价价格指数(线上)及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
