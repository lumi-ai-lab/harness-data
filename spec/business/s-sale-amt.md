# 销售额指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code saleAmt --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 销售额 |
| 指标英文 code | `saleAmt` |
| 业务定义 | 门店销售商品的总金额 |
| 统计逻辑 | 原价销售额减去日结相关优惠金额后，剩余的结算金额 |
| 业务环节 | 销售经营 |

## 指标定位

- 销售额是经营分析 `/report/2` 客数渗透率（`custPenetrationRate`）的一级子指标，属于规模类指标。
- 所属维度：用户渗透维度。
- 报告章节：第三章 用户渗透维度深度拆解。
- 在报告中与客数、客单价联动展示，用于说明用户规模和经营结果。
- 固定拆解链路：`客数渗透率 -> 销售额 -> 19点前销售占比 -> 19点前销售重量、订单满足率`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 19点前销售占比 | `bf19SaleRate` | 19点前链路 |
| 二级子指标 | 19点前销售重量 | `bf19SaleWeight` | 19点前链路 |
| 二级子指标 | 订单满足率 | `satisfiedRate` | 19点前链路 |

## 边界与禁放规则

- 销售额归用户渗透维度，固定放入第三章，不得放入第四章（品效）和第五章（供应链）。
- 客数、19点前客数、客单价、19点前客单价、全链路毛利率、全链路毛利额及其下游指标不得作为销售额主指标行。
- 品效、商品订购渗透率、定价毛利率、售价价格指数、活跃供应商数、供应商三率不得作为销售额报告指标行。
- 区域、品类、趋势证据只能用于解释销售额及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
- 根因必须受 CLI 证据约束，只有趋势或结构异常时只能写有限推断。
