# 19点前件单价指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code bf19PerPieceAmt --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 19点前件单价 |
| 指标英文 code | `bf19PerPieceAmt` |
| 业务定义 | 清仓时段前每件商品的平均售价 |
| 统计逻辑 | 19点前销售额 / 19点前销售件数 |
| 业务环节 | 销售经营 |

## 指标定位

- 19点前件单价是客数渗透率树中19点前客单价的叶子子指标。
- 所属维度：客数渗透率维度（用户渗透维度）。
- 报告章节：第三章 用户渗透维度深度拆解。
- 所属指标组：19点前链路。
- 固定拆解链路：`客数渗透率 -> 客单价 -> 19点前客单价 -> 19点前件单价`。

## 边界与禁放规则

- 19点前件单价是当前主指标，19点前客单价、客单价和客数渗透率只能用于父级传导，不能替代主指标。
- 19点前单均件数只作为同组19点前链路件数补充，不替代当前指标。
- 销售额、客数、毛利率、毛利额及其下游指标不得作为本报告主指标行。
- 品效维度指标（品效、商品订购渗透率、定价毛利率、售价价格指数等）不得放入本章节作为主指标行。
- 19点前链路其他指标（19点前销售占比、19点前客单重量、19点前PI值、19点前复购率、19点前客数）可在同组上下文分析中作为背景说明，但不得喧宾夺主。
- 全链路毛利率、门店毛利率、供应链毛利率可在影响分析中作为背景传导说明，但不得扩展为主章节。
- 区域、品类、趋势证据只能用于解释19点前件单价结构分化和异常，不扩展为经营总览。报告模板不单独设立区域或品类拆解章节（对应经营分析报告的第四章和第五章）。
- CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明。
