# 19点前销售占比指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code bf19SaleRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 19点前销售占比 |
| 指标英文 code | `bf19SaleRate` |
| 业务定义 | 清仓时段前销售额占全天销售额的比例 |
| 统计逻辑 | 门店19点前销售额 / 销售额 |
| 业务环节 | 销售经营 |

## 指标定位

- 19点前销售占比是销售额的子指标，属于19点前链路指标组。
- 所属维度：用户渗透维度（用户行为链路）。
- 报告章节：第三章 用户渗透维度深度拆解。
- 固定拆解链路：`19点前销售占比 -> 19点前销售重量、订单满足率`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 子指标 | 19点前销售重量 | `bf19SaleWeight` | 19点前链路 |
| 子指标 | 订单满足率 | `satisfiedRate` | 19点前链路（用户行为链路） |

## 边界与禁放规则

- 19点前链路指标归用户渗透维度，不得放入品效章节（第四章）或供应链章节（第五章）。
- 订单满足率归用户行为链路，不得放入供应链章节。
- 品效指标、供应链指标不得通过19点前链路交叉引用放入用户渗透章节。
- 区域、品类、趋势证据只能用于解释19点前销售占比及其下钻链路。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
