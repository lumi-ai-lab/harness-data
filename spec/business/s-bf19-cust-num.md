# 19点前客数指标报告规则

> 数据来源：`qdm-cmr-cli indicator detail --code bf19CustNum --full`

该文件用于经营分析下客数渗透率树中的19点前客数专项报告。取数固定使用 `qdm-cmr-cli report business`，指标固定为 `19点前客数` 或 `bf19CustNum`。

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 19点前客数 |
| 指标英文 code | `bf19CustNum` |
| 业务定义 | 清仓时段前消费的顾客订单数 |
| 统计逻辑 | 门店清仓时段前的来客数 |
| 业务环节 | 销售经营 |

## 指标位置

- 当前指标 code：`bf19CustNum`
- 当前指标中文名：19点前客数
- 所属一级核心指标：客数渗透率 `custPenetrationRate`
- 上级指标：客数渗透率 `custPenetrationRate`、客数 `custNum`
- 父指标：客数 `custNum`
- 子指标：19点前PI值 `bf19CategoryStoreCustRate`、19点前复购率 `bf19MemberRepurchaseRate`
- 指标组：19点前链路

固定拆解链路：

`客数渗透率 -> 客数 -> 19点前客数 -> 19点前PI值、19点前复购率`

## 指标归属

| 指标 | 所属链路 | 报告章节 | 禁止放入位置 |
| --- | --- | --- | --- |
| 客数渗透率 | 上级指标（一级核心） | 父子链路与传导判断 | 作为19点前客数主指标替代项 |
| 客数 | 父指标 | 父子链路与传导判断 | 作为19点前客数主指标替代项 |
| 19点前客数 | 当前指标 | 第三章 用户渗透维度深度拆解 | 第四章（品效）、第五章（供应链） |
| 19点前PI值 | 子指标 | 早时段质量与复购拆解 | 客单价、毛利章节 |
| 19点前复购率 | 子指标 | 早时段质量与复购拆解 | 客单价、毛利章节 |

## 允许解释链路

- 19点前客数变化可解释为早时段客流规模、品类触达质量（PI值）和复购行为共同作用。
- 客数和客数渗透率只用于父级传导，不能把客单价、销售额、毛利链路展开成19点前客数报告主章节。
- 19点前PI值和19点前复购率只用于解释早时段客流质量和复购，不得替代当前指标。
- 区域、品类、趋势证据可用于定位19点前客数结构分化和异常。

## 禁放规则

- 19点前客数属于用户渗透维度，固定放入第三章 用户渗透维度深度拆解，禁止放入第四章（品效）和第五章（供应链）。
- 客单价、19点前客单价、19点前单均件数、19点前件单价及其下游指标不得作为19点前客数报告主指标行。
- 销售额、19点前销售占比、19点前销售重量、订单满足率不得作为19点前客数报告主指标行。
- 全链路毛利率、全链路毛利额、门店毛利率、门店毛利额及其下游指标不得作为19点前客数报告主指标行。
- 品效、商品订购渗透率、定价毛利率、售价价格指数、活跃供应商数、供应商三率不得作为19点前客数报告指标行。
- 不得使用本地 demo、静态样例、经验估算或模板占位符替代 CLI 返回事实。
- CLI 未返回的指标行、区域、品类、趋势点直接省略。
- 根因必须受 CLI 证据约束，只有趋势或结构异常时只能写有限推断。

## 数据来源规则

- 所有数值、同比、环比、阈值、排名、异常和根因必须来自 CLI 输出。
- 必要来源为 `report business indicators`、`area`、`category`、`trend`。
- 若必要模块失败或 `inject-template` 未成功，不得生成最终报告。
