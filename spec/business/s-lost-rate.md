# 损耗率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code lostRate --full`

## 基本信息
| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 损耗率 |
| 指标英文 code | `lostRate` |
| 业务定义 | 由于各种原因导致的门店商品价值减少占门店进货额和期初期末库存差额的比例 |
| 统计逻辑 | 损耗额 /（进货额+期初库存金额 - 期末库存金额） |
| 业务环节 | 销售经营 |

## 指标定位
- 损耗率是定价毛利率（prePriceProfitRate）的子指标，属于品效维度下的履约与损耗类叶子指标。
- 所属维度：品效维度。
- 报告章节：第四章 品效维度深度拆解。
- 固定拆解链路：`品效 -> 定价毛利率 -> 损耗率`。

## 下钻子指标
该指标为叶子指标，无子指标。

## 边界与禁放规则

- 损耗率固定归入品效定价毛利率拆解，不得放入第三章（用户渗透）、第五章（供应链）。
- 损耗率是叶子指标，无下钻子指标，不得单独作为高亮章节展开。
- 销售额、客数、客单价、19点前链路指标不得作为损耗率报告主指标行。
- 预期毛利率、出库折让率、时段折扣率、促销折扣率可作为同链路补充背景，不得作为主指标行。
- 区域、品类、趋势证据只能用于解释损耗率，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
- 损耗率 valueUnit=3（小数比率），报告中需×100转为百分比展示；同比/环比 unit=3 表示百分点变化。
