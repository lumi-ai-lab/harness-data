# 采购价格指数指标详情

| 指标英文 code | `purchasePriceIndex` |

| 业务环节 | 价格管理 |

## 指标定位

- 采购价格指数是售价价格指数(线上)（`priceIndex`）的叶子子指标，属于品效维度下的定价与折扣策略类指标。
- 所属维度：品效维度。
- 报告章节：第四章 品效维度深度拆解。
- 固定拆解链路：`品效 -> 售价价格指数(线上) -> 采购价格指数`。
- 数据覆盖：该指标当前仅覆盖蔬菜品类（对标真甜农服蔬菜采购价），其余 6 个大分类（水产、肉禽蛋、冷藏加工、水果、预制菜、猪肉）无有效数据。区域维度仅粤东、粤西有有效数据，华东和运营直管无数据。

## 边界与禁放规则

- 不得放入第三章（用户渗透）、第五章（供应链）。
- 采购价格指数是本报告唯一主指标；售价价格指数(线上)只用于父级传导，不能替代主指标。
- 品效、商品订购渗透率、定价毛利率、损耗率不得作为本报告主指标行。
- 客数渗透率、销售额、客数、客单价、全链路毛利率、全链路毛利额、活跃供应商数不得作为本报告主指标行。
- 区域、品类、趋势证据只能用于解释采购价格指数及其对上游的传导，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
