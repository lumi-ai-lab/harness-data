# 客数指标报告规则

该文件用于经营分析下客数渗透率树中的客数专项报告。取数固定使用 `qdm-cmr-cli report business`，指标固定为 `客数` 或 `custNum`。

> 数据来源：`qdm-cmr-cli indicator detail --code custNum --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 来客数 |
| 指标英文 code | `custNum` |
| 业务定义 | 每天消费的顾客订单数 |
| 统计逻辑 | 按销售小票ID统计的订单数（物料大分类订单数为0） |
| 业务环节 | 销售经营 |
| 指标ID | 1877291253581123586 |
| valueUnit | 1（整数值，店日均客数） |
| 阈值 | 无（CLI 未返回 threshold） |

## 指标位置

- 当前指标 code：`custNum`
- 当前指标中文名：来客数
- 父指标：客数渗透率 `custPenetrationRate`
- 子指标：19点前客数 `bf19CustNum`
- 叶子指标：19点前PI值 `bf19CategoryStoreCustRate`、19点前复购率 `bf19MemberRepurchaseRate`
- 指标组：规模类指标

固定拆解链路：

`客数渗透率 -> 客数 -> 19点前客数 -> 19点前PI值、19点前复购率`

## 指标归属

| 指标 | 所属链路 | 报告章节 | 禁止放入位置 |
| --- | --- | --- | --- |
| 客数渗透率 | 父指标 | 父子链路与传导判断 | 作为客数主指标替代项 |
| 客数 | 当前指标 | 客数整体表现 | 第四章（品效）、第五章（供应链） |
| 19点前客数 | 子指标 | 早时段客流承接拆解 | 客单价、毛利章节 |
| 19点前PI值 | 叶子指标 | 早时段客流承接拆解 | 客单价、毛利章节 |
| 19点前复购率 | 叶子指标 | 早时段客流承接拆解 | 品效、供应商专项章节 |

## 允许解释链路

- 客数变化可解释为整体客流规模、早时段客流、PI触达或复购共同作用。
- 客数渗透率只用于父级传导，不能把客单价、毛利链路展开成客数报告主章节。
- 区域、品类、趋势证据可用于定位客数结构分化和异常。

## 禁放规则

- 客单价、19点前客单价、19点前单均件数、19点前件单价及其下游指标不得作为客数报告主指标行。
- 销售额、19点前销售占比、19点前销售重量、订单满足率不得作为客数报告主指标行。
- 全链路毛利率、全链路毛利额、门店毛利率、门店毛利额及其下游指标不得作为客数报告主指标行。
- 品效、商品订购渗透率、定价毛利率、售价价格指数、活跃供应商数、供应商三率不得作为客数报告指标行。
- 不得使用本地 demo、静态样例、经验估算或模板占位符替代 CLI 返回事实。
- CLI 未返回的指标行、区域、品类、趋势点直接省略。
- 根因必须受 CLI 证据约束，只有趋势或结构异常时只能写有限推断。

## 数据来源规则

- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出。
- 必要来源为 `report business indicators`、`area`、`category`、`trend`。
- 若必要模块失败或 `inject-template` 未成功，不得生成最终报告。
