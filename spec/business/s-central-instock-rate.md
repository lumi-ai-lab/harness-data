# 集采入库占比指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code centralInstockRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 集采入库占比 |
| 指标英文 code | `centralInstockRate` |
| 业务定义 | 集采入库金额占整体入库金额的占比 |
| 统计逻辑 | （集采仓的调拨出库金额（不含税）- 集采仓的调拨退货入库金额（不含税）） / （集采仓的调拨出库金额（不含税）- 集采仓的调拨退货入库金额（不含税）+ 非集采仓的采购入库额（不含税）- 非集采仓的采购退货额（不含税）） |
| 业务环节 | 入库环节 |

## 指标定位

- 集采入库占比是活跃供应商数（`activeVenderNum`）的子指标，属于叶子指标，无下钻子指标。
- 所属维度：供应链维度。
- 报告章节：第五章 供应链维度深度拆解。
- 所属指标组：供应商合作与集采指标。
- 固定拆解链路：`活跃供应商数 -> 集采入库占比`（叶子，无进一步拆解）。

## 下钻子指标

无。集采入库占比是叶子指标，不向下拆解。

## 边界与禁放规则

- 集采入库占比固定归入供应链维度第五章，不得放入第三章（用户渗透维度深度拆解）或第四章（品效维度深度拆解）。
- 销售额、客数、客单价、19点前链路指标不得作为本指标的解释变量或主指标行。
- 准确率、准点率、合格率、三率综合得分虽同属供应链维度，但属于履约质量三率指标组，不得混入集采入库占比的分析链路。
- 区域、品类、趋势证据只能用于解释集采入库占比及其对活跃供应商数的贡献，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
