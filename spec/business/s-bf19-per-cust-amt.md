# 19点前客单价指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code bf19PerCustAmt --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 19点前客单价 |
| 指标英文 code | `bf19PerCustAmt` |
| 业务定义 | 清仓时段前每笔订单的平均消费金额 |
| 统计逻辑 | 19点前销售额 / 19点前客数 |
| 业务环节 | 销售经营 |

## 指标定位

- 19点前客单价是客数渗透率树中客单价的下钻子指标。
- 所属维度：用户渗透维度。
- 报告章节：第三章 用户渗透维度深度拆解。
- 所属指标组：19点前链路。
- 固定拆解链路：`客数渗透率 -> 客单价 -> 19点前客单价 -> 19点前单均件数、19点前件单价`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 子指标 | 19点前单均件数 | `bf19AvgPieceNum` | 19点前链路 |
| 子指标 | 19点前件单价 | `bf19PerPieceAmt` | 19点前链路 |

## 边界与禁放规则

- 禁止放入第四章（品效维度深度拆解）、第五章（供应链维度深度拆解）。
- 19点前客单价是当前主指标，客单价和客数渗透率只能用于父级传导，不能替代主指标。
- 19点前单均件数和19点前件单价只用于解释件数与价格驱动，不能替代主指标。
- 销售额、客数、毛利率、毛利额及其下游指标不得作为本报告主指标行。
- 19点前链路指标（含19点前销售占比、19点前销售重量、订单满足率、19点前客数、19点前PI值、19点前复购率）可在同组18点-20点时段分化分析中使用，但不得喧宾夺主。
- 品效维度指标（品效、商品订购渗透率、定价毛利率、售价价格指数等）不得放入本章节作为主指标行。
- 全链路毛利率、门店毛利率、供应链毛利率可在影响分析中作为背景传导说明，但全链路盈利链路不得扩展为主章节。
- 区域、品类、趋势证据只能用于解释19点前客单价及其下钻链路，不扩展为经营总览。
- CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明。
