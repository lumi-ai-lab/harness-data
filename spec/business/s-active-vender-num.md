# 活跃供应商数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code activeVenderNum --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 活跃供应商数 |
| 指标英文 code | `activeVenderNum` |
| 业务定义 | 统计周期内，有入库金额的去重供应商数量 |
| 统计逻辑 | 入库金额＞0的去重供应商数 |
| 业务环节 | 采购环节 |

## 指标定位

- 活跃供应商数是经营分析 `/report/2` 的三大一级核心指标之一（另两个为客数渗透率、品效）。
- 所属维度：供应链维度。
- 报告章节：第二章 核心指标总览 + 第五章 供应链维度深度拆解。
- 固定拆解链路：`活跃供应商数 -> 集采入库占比、三率综合得分 -> 准确率、准点率、合格率`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 集采入库占比 | `centralInstockRate` | 供应商合作与集采指标 |
| 一级子指标 | 三率综合得分 | `threeRateScore` | 供应商合作与集采指标 |
| 二级子指标 | 准确率 | `vendorAccuracyRate` | 履约质量三率指标 |
| 二级子指标 | 准点率 | `vendorIntimeRate` | 履约质量三率指标 |
| 二级子指标 | 合格率 | `vendorQualificationRate` | 履约质量三率指标 |

## 边界与禁放规则

- 活跃供应商数不得放入第三章（用户渗透）和第四章（品效）章节作为主指标行。
- 销售额、客数、客单价、19点前链路指标不得放入供应链章节。
- 品效、商品订购渗透率、定价毛利率、售价价格指数不得放入供应链章节。
- 出库折让率固定归入品效维度，不得放入供应链章节。
- 准确率、准点率、合格率、三率综合得分固定归入供应链维度，不得放入品效章节。
- 区域、品类、趋势证据只能用于解释活跃供应商数及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
