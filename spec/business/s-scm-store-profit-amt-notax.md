# 供应链毛利额指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code scmStoreProfitAmtNotax --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 供应链到店毛利额（不含税） |
| 指标英文 code | `scmStoreProfitAmtNotax` |
| 业务定义 | 仓库配送到门店的商品毛利额，不含税款 |
| 统计逻辑 | 出库到店金额（不含税）-abs(门店退货额（SAP）（不含税）)-(出库到店成本（不含税）-abs(门店退货成本（不含税）)) |
| 业务环节 | 仓储环节 |

## 指标定位

- 供应链毛利额是客数渗透率维度下全链路盈利组的叶子指标。
- 所属维度：客数渗透率维度（用户渗透维度）。
- 报告章节：第三章 用户渗透维度深度拆解。
- 注意：虽名为"供应链"毛利额，但在经营分析报告中归入用户渗透链路的全链路盈利部分，不放入第五章供应链维度。
- 固定拆解链路：`客数渗透率 -> 全链路毛利额 -> 供应链毛利额`。
- 上级指标：客数渗透率 `custPenetrationRate`。
- 父指标：全链路毛利额 `fullLinkStoreProfitAmtNotax`。
- 同组指标：门店毛利额 `profitAmt`。

## 下钻子指标

无（叶子指标）。

## 指标配置

| 属性 | 值 |
| :--- | :--- |
| valueUnit | 2（金额/比率直接使用，如 1552.52） |
| threshold | null（无预设阈值） |
| 同比环比 unit | 2（比率变化，如 +0.2636 表示 +26.36%） |

## 边界与禁放规则

- 供应链毛利额是当前主指标，全链路毛利额和客数渗透率只能用于父级传导。
- 门店毛利额只能作为同组补充，不得替代主指标。
- 全链路毛利率、门店毛利率、供应链毛利率、销售额、客数、客单价及其下游指标不得作为本报告主指标行。
- 禁放：第四章（品效维度）、第五章（供应链维度）。
- 区域、品类、趋势证据可用于定位供应链毛利额结构分化和异常。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
- 诊断必须基于已返回数据，使用"现象 -> 影响 -> 推断"的逻辑，不把通用业务常识写成已发生事实。
- 根因必须受 CLI 证据约束；CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
