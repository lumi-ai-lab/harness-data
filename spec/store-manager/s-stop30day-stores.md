# 停业超30天门店数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code stop30dayStores --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 停业超30天门店数 |
| 指标英文 code | `stop30dayStores` |
| 业务定义 | 连续停业超过30天的门店数量，反映长期停业和资源占用风险 |
| 统计逻辑 | 统计当前处于停业状态且停业天数超过30天的门店总数 |
| 业务环节 | 门店管理环节 |

## 指标定位

- 停业超30天门店数是门店管理 `/report/1` 的门店规模与健康度维度下的叶子指标。
- 所属维度：门店规模与健康度。
- 报告章节：第三章 门店规模与健康度维度深度拆解。
- 归属链路：`营业门店数 -> 净增门店数 -> 闭店数 -> 停业超30天门店数`。
- 父指标：`closeStores`（闭店数）。

## 父子关系

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 父指标 | 闭店数 | `closeStores` | 门店开闭店与结构健康度指标 |
| 当前 | 停业超30天门店数 | `stop30dayStores` | 门店开闭店与结构健康度指标 |

## 边界与禁放规则

- 停业超30天门店数归入门店开闭店与结构健康度指标组，不得放入门店盈利与运营效率章节（第四章）。
- 品类口径固定为全品类，不做品类下钻。
- 区域支持下钻；未指定区域时固定为全国（不含港澳）。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
