# 尾部门店不良率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code tailLossRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 尾部门店不良率 |
| 指标英文 code | `tailLossRate` |
| 业务定义 | 尾部门店中不良门店的占比 |
| 业务环节 | 门店盈利与运营效率 |

## 指标定位

- 尾部门店不良率是不良率（lossRate）的子指标，属于不良率分层指标组（isGroup: true, layout: vertical）的叶子指标。
- 所属维度：门店盈利与运营效率。
- 报告章节：第四章 门店盈利与运营效率维度深度拆解。
- 固定拆解链路：`门店净利润 -> 盈亏平衡点 -> 不良率 -> 尾部门店不良率`。
- 用于按门店层级分档展示不同梯队门店的不良率水平，识别尾部梯队门店中的不良风险，为门店退出或整改提供数据依据。

## 下钻子指标

该指标为叶子指标，无子指标。

## 边界与禁放规则

- 尾部门店不良率固定归入不良率分层指标组，不得单独放入第三章（门店规模与健康度）。
- 尾部门店不良率 valueUnit=3（小数比率），报告中需×100转为百分比展示；同比/环比 unit=3 表示百分点变化。
- 门店净利润、盈亏平衡点、营业门店数、坪效、人效不得作为本报告主指标行。
- 不良率及其余三个分层子指标（头部、中上、中下）只可作为同组对比背景，不得替代当前指标。
- 品类口径固定为全品类，不做品类下钻。
- 区域、趋势证据只能用于解释尾部门店不良率，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
