# 盈亏平衡点指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code breakEvenPoint --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 盈亏平衡点 |
| 指标英文 code | `breakEvenPoint` |
| 业务定义 | 门店达到盈亏平衡所需的最低销售额或收入水平，反映单店盈利门槛和成本压力 |
| 统计逻辑 | 基于门店固定成本（员工工资、租金和物业管理费、水电费等）和变动成本综合计算的门店盈亏平衡销售额 |
| 业务环节 | 门店管理环节 |

## 指标定位

- 盈亏平衡点是门店管理 `/report/1` 的门店盈利与运营效率维度下的二级指标。
- 所属维度：门店盈利与运营效率。
- 报告章节：第四章 门店盈利与运营效率维度深度拆解。
- 归属链路：`门店净利润 -> 盈亏平衡点`。
- 父指标：`netProfit`（门店净利润）。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 二级子指标 | 损耗率 | `lossRate` | 盈利与成本结构指标 |
| 二级子指标 | 员工工资 | `storeTotalSalary` | 盈利与成本结构指标 |
| 二级子指标 | 租金和物业管理费 | `storeDormTotalRent` | 盈利与成本结构指标 |
| 二级子指标 | 店铺水电费 | `waterRent` | 盈利与成本结构指标 |
| 二级子指标 | 门店其他支出 | `storeOtherFee` | 盈利与成本结构指标 |

## 边界与禁放规则

- 盈亏平衡点归入门店盈利与运营效率维度，不得放入门店规模与健康度章节（第三章）。
- 品类口径固定为全品类，不做品类下钻，不输出品类排名、品类拖累或品类贡献。
- 区域支持下钻；未指定区域时固定为全国（不含港澳）。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
- 盈亏平衡点固定归入门店净利润拆解链路，不得放入其他章节作为独立指标行。
- 营业门店数、开店数、闭店数等门店规模指标不得放入盈亏平衡点章节。
