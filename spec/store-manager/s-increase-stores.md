# 净增门店数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code increaseStores --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 净增门店数 |
| 指标英文 code | `increaseStores` |
| 业务定义 | 报告期内净增加的门店数量 |
| 统计逻辑 | 开店数 - 闭店数 |
| 业务环节 | 门店管理环节 |

## 指标定位

- 净增门店数是营业门店数（`stores`）的一级子指标，反映门店规模的净变动。
- 所属维度：门店管理维度。
- 报告章节：第三章 门店管理维度深度拆解 > 净增门店数分析。
- 固定拆解链路：`净增门店数 -> 开店数、闭店数 -> 待开业门店数、停业超30天门店数`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 开店数 | `openStores` | 门店变动 |
| 一级子指标 | 闭店数 | `closeStores` | 门店变动 |
| 二级子指标 | 待开业门店数 | `unopenStores` | 门店变动 |
| 二级子指标 | 停业超30天门店数 | `stop30dayStores` | 门店异常 |

## 边界与禁放规则

- 销售额、客数、客单价、品效、19点前链路指标不得放入净增门店数章节作为主指标行。
- 品类数据不得放入净增门店数章节（门店管理域不涉及品类维度）。
- 区域、趋势证据只能用于解释净增门店数及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
