# 闭店数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code closeStores --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 闭店数 |
| 指标英文 code | `closeStores` |
| 业务定义 | 报告期内完成闭店流程的门店数量 |
| 统计逻辑 | 统计报告期内状态由"营业中"或"停业"转为"已关闭"的门店数量 |
| 业务环节 | 门店管理环节 |

## 指标定位

- 闭店数是净增门店数（`increaseStores`）的一级子指标，反映门店收缩程度。
- 所属维度：门店管理维度。
- 报告章节：第三章 门店管理维度深度拆解 > 闭店数分析。
- 固定拆解链路：`闭店数 -> 停业超30天门店数`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 停业超30天门店数 | `stop30dayStores` | 门店异常 |

## 边界与禁放规则

- 销售额、客数、客单价、品效、19点前链路指标不得放入闭店数章节作为主指标行。
- 品类数据不得放入闭店数章节（门店管理域不涉及品类维度）。
- 区域、趋势证据只能用于解释闭店数及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
