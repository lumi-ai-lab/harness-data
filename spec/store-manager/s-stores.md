# 营业门店数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code stores --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 营业门店数 |
| 指标英文 code | `stores` |
| 业务定义 | 当前处于正常营业状态的门店总数 |
| 统计逻辑 | 统计截止日期当天，所有状态为"营业中"的门店数量 |
| 业务环节 | 门店管理环节 |

## 指标定位

- 营业门店数是门店管理 `/report/1` 的一级核心指标（含 `showTable` 表格展示）。
- 所属维度：门店管理维度。
- 报告章节：第一章 核心指标总览 + 第三章 门店管理维度深度拆解。
- 固定拆解链路：`营业门店数 -> 净增门店数、存量门店数、停业门店数 -> 开店数、闭店数 -> 待开业门店数、停业超30天门店数`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 净增门店数 | `increaseStores` | 门店变动 |
| 一级子指标 | 存量门店数 | `stockStores` | 门店存量 |
| 一级子指标 | 停业门店数 | `stopBusinessStores` | 门店异常 |
| 二级子指标 | 开店数 | `openStores` | 门店变动 |
| 二级子指标 | 闭店数 | `closeStores` | 门店变动 |
| 三级子指标 | 待开业门店数 | `unopenStores` | 门店变动 |
| 三级子指标 | 停业超30天门店数 | `stop30dayStores` | 门店异常 |

## 边界与禁放规则

- 销售额、客数、客单价、品效、19点前链路指标不得放入营业门店数章节作为主指标行。
- 活跃供应商数、三率综合得分不得放入营业门店数章节。
- 品类数据不得放入营业门店数章节（门店管理域不涉及品类维度）。
- 区域、趋势证据只能用于解释营业门店数及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
