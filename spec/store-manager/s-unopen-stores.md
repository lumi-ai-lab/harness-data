# 待开业门店数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code unopenStores --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 待开业门店数 |
| 指标英文 code | `unopenStores` |
| 业务定义 | 已批准筹建但尚未正式营业的门店数量 |
| 统计逻辑 | 统计截止日期当天，所有状态为"待开业"或"筹建中"的门店数量 |
| 业务环节 | 门店管理环节 |

## 指标定位

- 待开业门店数是开店数（`openStores`）的叶子子指标，反映门店筹建管道储备。
- 所属维度：门店管理维度。
- 报告章节：第三章 门店管理维度深度拆解 > 待开业门店数分析。
- 无下级拆解子指标。

## 下钻子指标

无下级子指标（叶子指标）。

## 边界与禁放规则

- 销售额、客数、客单价、品效、19点前链路指标不得放入待开业门店数章节作为主指标行。
- 品类数据不得放入待开业门店数章节（门店管理域不涉及品类维度）。
- 区域、趋势证据只能用于解释待开业门店数，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
