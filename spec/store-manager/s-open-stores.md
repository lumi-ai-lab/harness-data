# 开店数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code openStores --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 开店数 |
| 指标英文 code | `openStores` |
| 业务定义 | 报告期内完成开业流程并正式营业的门店数量 |
| 统计逻辑 | 统计报告期内状态由"待开业"或"筹建中"转为"营业中"的门店数量 |
| 业务环节 | 门店管理环节 |

## 指标定位

- 开店数是净增门店数（`increaseStores`）的一级子指标，反映门店扩张速度。
- 所属维度：门店管理维度。
- 报告章节：第三章 门店管理维度深度拆解 > 开店数分析。
- 固定拆解链路：`开店数 -> 待开业门店数`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 待开业门店数 | `unopenStores` | 门店变动 |

## 边界与禁放规则

- 销售额、客数、客单价、品效、19点前链路指标不得放入开店数章节作为主指标行。
- 品类数据不得放入开店数章节（门店管理域不涉及品类维度）。
- 区域、趋势证据只能用于解释开店数及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
