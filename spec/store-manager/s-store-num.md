# 门店人数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code storeNum --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 门店人数 |
| 指标英文 code | `storeNum` |
| 业务定义 | 门店实际在岗人员数量 |
| 统计逻辑 | 统计周期内门店平均在岗人员数量 |
| 业务环节 | 门店运营 |

## 指标定位

- 所属维度：盈利效率维度。
- 父指标：人效（`laborEffective`）。
- 报告章节：第三章 门店盈利效率深度拆解。
- 拆解链路：`门店净利润 -> 人效 -> 门店人数`。
- 所属指标组：盈利效率。

## 下钻子指标

该指标为叶子指标，无子指标。

## 边界与禁放规则

- 门店人数不得放入门店规模与健康度章节。
- 营业门店数、开店数、闭店数、停业门店数不得放入门店人数章节。
- 区域、趋势证据只能用于解释门店人数及其父指标人效，不得扩展为门店管理总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
