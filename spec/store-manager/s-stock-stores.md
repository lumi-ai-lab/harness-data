# 存量门店数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code stockStores --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 存量门店数 |
| 指标英文 code | `stockStores` |
| 业务定义 | 当前系统中存在的门店总数，反映门店基础盘稳定性 |
| 统计逻辑 | 统计系统中所有门店的数量（含正常营业、停业、待开业等各状态门店） |
| 业务环节 | 门店管理环节 |

## 指标定位

- 存量门店数是门店管理 `/report/1` 的门店规模与健康度维度下的叶子指标。
- 所属维度：门店规模与健康度。
- 报告章节：第三章 门店规模与健康度维度深度拆解。
- 归属链路：`营业门店数 -> 存量门店数`。
- 父指标：`stores`（营业门店数）。

## 父子关系

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 父指标 | 营业门店数 | `stores` | 门店规模与净增长指标 |
| 当前 | 存量门店数 | `stockStores` | 门店规模与净增长指标 |

## 边界与禁放规则

- 存量门店数归入门店规模与净增长指标组，不得放入门店盈利与运营效率章节（第四章）。
- 品类口径固定为全品类，不做品类下钻。
- 区域支持下钻；未指定区域时固定为全国（不含港澳）。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
