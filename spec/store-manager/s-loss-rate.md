# 不良率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code lossRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 不良率 |
| 指标英文 code | `lossRate` |
| 业务定义 | 不良门店数占纳入不良率统计的门店数的占比 |
| 业务环节 | 门店盈利与运营效率 |

## 指标定位

- 不良率是盈亏平衡点（breakEvenPoint）的子指标，属于门店盈利与运营效率维度下的盈利与成本结构类指标。
- 所属维度：门店盈利与运营效率。
- 报告章节：第四章 门店盈利与运营效率维度深度拆解。
- 固定拆解链路：`门店净利润 -> 盈亏平衡点 -> 不良率 -> 头部门店不良率、中上门店不良率、中下门店不良率、尾部门店不良率`。
- 不良率以虚线（lineType: dashed）连接至盈亏平衡点，其四个子指标以垂直分组（isGroup: true, layout: vertical）形式展示。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 头部门店不良率 | `headLossRate` | 不良率分层 |
| 一级子指标 | 中上门店不良率 | `upperLossRate` | 不良率分层 |
| 一级子指标 | 中下门店不良率 | `lowerLossRate` | 不良率分层 |
| 一级子指标 | 尾部门店不良率 | `tailLossRate` | 不良率分层 |

## 边界与禁放规则

- 不良率固定归入门店盈利与运营效率章节，不得放入第三章（门店规模与健康度）。
- 不良率 valueUnit=3（小数比率），报告中需×100转为百分比展示；同比/环比 unit=3 表示百分点变化。
- 门店净利润、营业门店数、坪效、人效不得作为不良率报告主指标行。
- 成本支出指标（员工工资、租金、水电费等）只可在解释不良率根因时作为补充背景，不得作为主指标行。
- 品类口径固定为全品类，不做品类下钻，不输出品类排名、品类拖累或品类贡献。
- 区域、趋势证据只能用于解释不良率及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
