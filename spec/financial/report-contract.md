# 财务核心指标归属规范

> 该文件是财务核心指标深度报告的权威指标归属说明。取数前必须读取，用于取数和业务规则判断；template 注入后只注入 selected playbook 绑定的 template 正文。

## 硬规则

- 财务报告只使用 signal 后二阶段注入的 template 章节结构；signal 前不读取、不使用 template。
- 公司/财务报表只支持周、月时间粒度；禁止使用日维度，禁止对 company 报表传入 `--date`。
- 用户询问昨天、今天或具体日期时，必须转换为该日期所在 ISO 周，并在报告中明确说明“不支持日维度，已按所在周统计”。
- 区域维度可选；用户未指定区域时不强制追加区域过滤，按 CLI 默认全国口径执行。
- 品类维度不可选，默认全品类；禁止传入 `--category-type` 或 `--category`。
- `核心指标总览` 只展示四类核心指标：EBITDA、公司营业收入、公司毛利额、费率/额。
- EBITDA、公司营业收入、公司毛利额、费率/额是财务报告的总纲指标。
- 收入结构指标固定归入收入结构维度。
- 毛利分项指标固定归入毛利贡献维度。
- 费用率与费用额固定归入费用管控维度。
- 任何指标只能放入其对应维度的主章节，禁止跨维度混放。
- 不得使用 `financial-demo.md` 中的示例数值替代 CLI 返回值。
