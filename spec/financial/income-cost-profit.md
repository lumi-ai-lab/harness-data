# 财务收入毛利费用规则

- EBITDA、公司营业收入、公司毛利额、费率/额是财务报告的总纲指标。
- 收入结构指标固定归入收入结构维度。
- 毛利分项指标固定归入毛利贡献维度。
- 费用率与费用额固定归入费用管控维度。
