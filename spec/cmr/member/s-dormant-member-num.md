# 休眠期会员数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code dormantMemberNum --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 休眠期会员数 |
| 指标英文 code | `dormantMemberNum` |
| 业务定义 | 过去30天中没有消费，但90天内有过消费的会员数 |
| 统计逻辑 | 同时满足下列条件的会员id去重计数：1. 过去30天消费次数=0次；2. 过去31-90天内有消费记录 |
| 数据来源 | 用户报表 `/report/3`（`qdm-cmr-cli report user`） |

## 指标定位

- 休眠期会员数是用户报表 `/report/3` 中活跃用户数（`activeMemberNum`）的下游指标。
- 所属维度：用户规模与分层结构。
- 报告章节：第三章 用户规模与分层结构深度拆解。
- 父指标：活跃用户数（`activeMemberNum`）。
- 子指标：用户挽回率（`winbackMemberRate`），用于衡量从休眠状态唤醒会员的效果。
- 休眠期会员数承接活跃用户数中"未消费"部分的用户规模，反映用户活跃度衰减情况。

## 下钻子指标

| 层级 | 指标 | code | 说明 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 用户挽回率 | `winbackMemberRate` | 衡量休眠会员被重新激活的比例，仅在CLI返回有值时展示 |

## 边界与禁放规则

- 休眠期会员数固定归入"用户规模与分层结构"维度（第三章），禁止放入第四章（用户价值与复购转化）和第五章（用户触达与渠道效率）。
- 不得作为经营分析 `/report/2` 的指标行。
- 休眠期会员数不支持下钻品类维度分析（用户报表不支持品类过滤）。
- 区域、趋势证据只能用于解释休眠期会员数及其下钻指标的表现，不得扩展为用户总览报告。
- 用户挽回率仅在 CLI 返回有值时展示，不得在无数据时自行补充或推断。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
