# 流失期用户数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code churnedMemberNum --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 流失期用户数（CLI detail 返回"流失期会员数"） |
| 指标英文 code | `churnedMemberNum` |
| 业务定义 | 过去90天中没有消费，但历史至今有过消费的会员数 |
| 统计逻辑 | 同时满足下列条件的会员id去重计数：1. 过去90天消费次数=0次；2. 21年至过去91天消费次数>=1 |
| 数据来源 | 用户报表 `/report/3`（`qdm-cmr-cli report user`） |

## 指标定位

- 流失期用户数是用户报表 `/report/3` 中活跃用户数（`activeMemberNum`）的下游叶子指标。
- 所属维度：用户规模与分层结构。
- 报告章节：第三章 用户规模与分层结构深度拆解。
- 父指标：活跃用户数（`activeMemberNum`）。
- 无子指标，为叶子指标。
- 流失期用户数反映超过90天未消费的历史用户规模，是衡量用户流失程度的关键指标。

## 下钻子指标

无。流失期用户数为叶子指标，无下钻子指标。

## 边界与禁放规则

- 流失期用户数固定归入"用户规模与分层结构"维度（第三章），禁止放入第四章（用户价值与复购转化）和第五章（用户触达与渠道效率）。
- 不得作为经营分析 `/report/2` 的指标行。
- 流失期用户数不支持下钻品类维度分析（用户报表不支持品类过滤）。
- 区域、趋势证据只能用于解释流失期用户数的表现，不得扩展为用户总览报告。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
