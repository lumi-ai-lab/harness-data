# 用户运营指标归属规范

> 该文件是用户运营深度报告的权威指标归属说明。取数前必须读取，用于取数和业务规则判断；template 注入后只注入 selected playbook 绑定的 template 正文。

## 硬规则

- 用户运营报告只使用 signal 后二阶段注入的 template 章节结构；signal 前不读取、不使用 template。
- 用户报表不支持品类过滤；品类口径写为用户报表默认全口径，不输出品类排名、品类拖累或品类贡献。
- 区域支持下钻；未指定区域时固定为全国（不含港澳）。
- `核心指标总览` 只展示 CLI 返回有值的一级核心指标：活跃用户数、会员复购率、会员销售占比。
- 活跃用户数、新消费用户数、会员分层活跃、休眠期会员数、流失期用户数、可触达用户数归入用户规模与分层结构。
- 会员复购率、消费会员数、复购会员数、复购会员消费频次、会员销售占比、交叉会员数、线上/线下消费会员数归入会员价值与复购转化。
- 可触达用户数、会员数、社群用户数、官媒用户数、抖音用户数归入用户触达与渠道效率。
- 指标配置存在但 CLI 没有返回值，不等于指标值为 0；最终报告应省略无值指标。
- 任何指标只能放入其对应维度的主章节，禁止跨维度混放。
