# 新客首单客单价指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code firstTranMemberPerCustAmt --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 新客首单客单价 |
| 指标英文 code | `firstTranMemberPerCustAmt` |
| 业务定义 | 统计周期内，首次消费会员的首笔订单的平均消费金额 |
| 统计逻辑 | 新客首次消费销售额 / 新消费会员数 |
| 业务环节 | 用户运营 |

## 指标定位

- 新客首单客单价是用户运营 `/report/3` 新消费用户数的子指标，属于用户规模与分层结构维度。
- 所属维度：用户规模与分层结构维度。
- 报告章节：第三章 用户规模与分层结构维度深度拆解。
- 指标组：新用户表现指标。
- 固定拆解链路：`活跃用户数 -> 新消费用户数 -> 新客首单客单价`。

## 下钻子指标

该指标为叶子指标，无子指标。

## 边界与禁放规则

- 用户报表不支持品类过滤；不输出品类排名、品类拖累或品类贡献。
- 新客首单客单价归入用户规模与分层结构维度，固定放入第三章，不得放入第四章（会员价值与复购转化）和第五章（用户触达与渠道效率）。
- 该指标为新消费用户数的质量指标，在报告中需在新消费用户数之后展示，用于描述新客消费质量。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
- 任何指标只能放入其对应维度的主章节，禁止跨维度混放。
