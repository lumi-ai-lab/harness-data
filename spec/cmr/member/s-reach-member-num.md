# 可触达用户数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code reachMemberNum --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 可触达用户数 |
| 指标英文 code | `reachMemberNum` |
| 业务定义 | 各渠道（小程序、社群、微信公众号、抖音）可触达的用户数量 |
| 统计逻辑 | 各渠道（小程序、社群、微信公众号、抖音）可触达的用户数量 |
| 数据来源 | 用户报表 `/report/3`（`qdm-cmr-cli report user`） |

## 指标定位

- 可触达用户数是用户报表 `/report/3` 中活跃用户数（`activeMemberNum`）的下游指标。
- 所属维度：跨维度指标，同时归属"用户规模与分层结构"（第三章）和"用户触达与渠道效率"（第五章）。
- 父指标：活跃用户数（`activeMemberNum`）。
- 子指标：会员数（`memberNum`）、社群用户数（`communityUserNum`）、官媒用户数、抖音用户数。
- 可触达用户数承接活跃用户数中"可触达"部分的用户规模，向下分解为各渠道触达用户数，衡量用户触达基础设施的覆盖能力。

## 下钻子指标

| 层级 | 指标 | code | 所属章节 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 会员数 | `memberNum` | 第五章 用户触达与渠道效率 |
| 一级子指标 | 社群用户数 | `communityUserNum` | 第五章 用户触达与渠道效率 |
| 一级子指标 | 官媒用户数 | -- | 第五章 用户触达与渠道效率 |
| 一级子指标 | 抖音用户数 | -- | 第五章 用户触达与渠道效率 |

## 边界与禁放规则

- 可触达用户数跨维度归属：第三章（用户规模与分层结构）和第五章（用户触达与渠道效率），禁止放入第四章（用户价值与复购转化）。
- 不得作为经营分析 `/report/2` 的指标行。
- 可触达用户数不支持下钻品类维度分析（用户报表不支持品类过滤）。
- 区域维度数据当前为 null（rows 为空），报告中只能按 CLI 事实描述，不得自行补充区域数据。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
