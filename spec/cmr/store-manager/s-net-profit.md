# 门店净利润指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code netProfit --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 门店净利润 |
| 指标英文 code | `netProfit` |
| 业务定义 | 门店整体盈利水平，反映门店经营成果和健康度的核心指标 |
| 统计逻辑 | 门店总收入减去门店总成本后的净利润 |
| 业务环节 | 门店管理环节 |

## 指标定位

- 门店净利润是门店管理 `/report/1` 的两大一级核心指标之一（另一个为营业门店数）。
- 所属维度：门店盈利与运营效率。
- 报告章节：第二章 核心指标总览 + 第四章 门店盈利与运营效率维度深度拆解。
- 固定拆解链路：`门店净利润 -> 盈亏平衡点、坪效、人效`。
- `showTable`：作为一级核心指标，需在核心指标总览中以表格形式展示。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 盈亏平衡点 | `breakEvenPoint` | 盈利与成本结构指标 |
| 一级子指标 | 坪效 | `areaEffective` | 运营效率指标 |
| 一级子指标 | 人效 | `laborEffective` | 运营效率指标 |

## 边界与禁放规则

- 门店净利润归入门店盈利与运营效率维度，不得放入门店规模与健康度章节（第三章）。
- 品类口径固定为全品类，不做品类下钻，不输出品类排名、品类拖累或品类贡献。
- 区域支持下钻；未指定区域时固定为全国（不含港澳）。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
- 营业门店数、开店数、闭店数、停业门店数等门店规模指标不得放入门店净利润章节作为主指标行。
