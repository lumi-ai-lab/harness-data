# 品效下钻指标归属规则

该文件用于经营分析下的品效专项报告。品效下钻仍归属 `business` domain，取数仍使用 `qdm-cmr-cli report business`。

## 固定拆解链路

`品效 -> 商品订购渗透率、定价毛利率、售价价格指数 -> 订购门店数、可订门店数、预期毛利率、出库折让率、时段折扣率、促销折扣率、损耗率、采购价格指数`

## 指标归属

| 指标 | 所属链路 | 报告章节 | 禁止放入位置 |
| --- | --- | --- | --- |
| 品效 | 总指标 | 品效整体表现 | 用户渗透、供应链章节 |
| 商品订购渗透率 | 商品订购渗透 | 商品订购渗透率拆解 | 供应链章节 |
| 订购门店数 | 商品订购渗透 | 商品订购渗透率拆解 | 定价毛利率、售价价格指数、供应链章节 |
| 可订门店数 | 商品订购渗透 | 商品订购渗透率拆解 | 定价毛利率、售价价格指数、供应链章节 |
| 定价毛利率 | 定价毛利 | 定价毛利率拆解 | 商品订购渗透率、供应链章节 |
| 预期毛利率 | 定价毛利 | 定价毛利率拆解 | 商品订购渗透率、供应链章节 |
| 出库折让率 | 定价毛利 | 定价毛利率拆解 | 商品订购渗透率、供应链章节 |
| 时段折扣率 | 定价毛利 | 定价毛利率拆解 | 商品订购渗透率、供应链章节 |
| 促销折扣率 | 定价毛利 | 定价毛利率拆解 | 商品订购渗透率、供应链章节 |
| 损耗率 | 定价毛利 | 定价毛利率拆解 | 商品订购渗透率、供应链章节 |
| 售价价格指数 | 售价价格 | 售价价格指数拆解 | 商品订购渗透率、供应链章节 |
| 采购价格指数 | 售价价格 | 售价价格指数拆解 | 商品订购渗透率、供应链章节 |

## 禁放规则

- 销售额、客数、客单价、19点前链路指标不得作为品效下钻章节的指标行。
- 准确率、准点率、合格率、三率综合得分、活跃供应商数不得放入品效下钻章节。
- 出库折让率固定归入定价毛利率拆解，不得放入供应链。
- 区域、品类、趋势证据只能解释品效链路，不得扩展成经营总览三大主线报告。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；缺失指标行直接省略。
