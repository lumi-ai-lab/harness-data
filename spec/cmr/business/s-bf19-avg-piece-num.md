# 19点前单均件数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code bf19AvgPieceNum --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 19点前单均件数 |
| 指标英文 code | `bf19AvgPieceNum` |
| 业务定义 | 清仓时段前每笔订单平均销售的商品份数 |
| 统计逻辑 | 19点前销售件数 / 19点前客数 |
| 业务环节 | 销售经营 |

## 指标定位

- 19点前单均件数是客数渗透率树中19点前客单价的叶子子指标。
- 所属维度：客数渗透率维度（用户渗透维度）。
- 报告章节：第三章 用户渗透维度深度拆解。
- 所属指标组：19点前链路。
- 固定拆解链路：`客数渗透率 -> 客单价 -> 19点前客单价 -> 19点前单均件数`。

## 父级链路与兄弟指标

| 层级 | 指标 | code | 关系 |
| :--- | :--- | :--- | :--- |
| 根指标 | 客数渗透率 | `custPenetrationRate` | 树根，经营分析三大一级核心指标之一 |
| 上级指标 | 客单价 | `perCustAmt` | 第二级父指标，反映单客消费水平 |
| 父指标 | 19点前客单价 | `bf19PerCustAmt` | 直接父指标，分解为件数驱动和价格驱动 |
| 当前指标 | 19点前单均件数 | `bf19AvgPieceNum` | 本指标，早时段每单购买件数 |
| 兄弟指标 | 19点前件单价 | `bf19PerPieceAmt` | 19点前客单价的另一叶子子指标，反映价格驱动 |

## 允许解释链路

- 19点前单均件数变化可解释为早时段购买行为（连单率、凑单意愿、客群结构）变化。
- 19点前客单价、客单价和客数渗透率只用于父级传导，不能替代当前指标。
- 19点前件单价只作为同组19点前链路价格补充，用于区分件数与价格驱动，不替代当前指标。
- 区域、品类、趋势证据可用于定位19点前单均件数结构分化和异常。
- 19点前链路同组指标（19点前销售占比、19点前销售重量、订单满足率、19点前客数、19点前PI值、19点前复购率）可在时段行为分化分析中作为补充证据，但不得喧宾夺主。

## 边界与禁放规则

- 19点前单均件数是当前主指标，19点前客单价、客单价和客数渗透率只能用于父级传导，不能替代主指标。
- 19点前件单价只作为同组19点前链路价格补充，不替代当前指标。
- 销售额、客数、毛利率、毛利额及其下游指标不得作为本报告主指标行。
- 品效维度指标（品效、商品订购渗透率、定价毛利率、售价价格指数等）不得放入本章节作为主指标行。（禁放主报告第四章内容）
- 供应链维度指标（活跃供应商数、三率综合得分、准确率、准点率、合格率等）不得放入本章节作为主指标行。（禁放主报告第五章内容）
- 全链路毛利率、门店毛利率、供应链毛利率可在影响分析中作为背景传导说明，但不得扩展为主章节。
- 区域、品类、趋势证据只能用于解释19点前单均件数结构分化和异常，不扩展为经营总览。
- CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明。
