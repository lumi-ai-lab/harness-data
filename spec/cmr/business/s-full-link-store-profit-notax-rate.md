# 全链路毛利率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code fullLinkStoreProfitNotaxRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 全链路到店毛利率（不含税） |
| 指标英文 code | `fullLinkStoreProfitNotaxRate` |
| 业务定义 | 全链路到店毛利额（不含税）占销售额的比例，反映整体经营效率 |
| 统计逻辑 | (供应链到店毛利额（不含税）+ 门店毛利额) / 销售额 |
| 业务环节 | 全链路 |

## 指标定位

- 全链路毛利率是客数渗透率树中客数渗透率的直接下钻子指标。
- 所属维度：客数渗透率维度（用户渗透维度）。
- 报告章节：第三章 用户渗透维度深度拆解。
- 所属指标组：全链路盈利。
- 固定拆解链路：`客数渗透率 -> 全链路毛利率 -> 门店毛利率、供应链毛利率`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 子指标 | 门店毛利率 | `profitRate` | 全链路盈利 |
| 子指标 | 供应链毛利率 | `scmStoreProfitNotaxRate` | 全链路盈利 |

## 边界与禁放规则

- 全链路毛利率是当前主指标，客数渗透率只能用于父级传导，不能替代主指标。
- 门店毛利率和供应链毛利率用于解释驱动来源，不能替代主指标。
- 销售额、客数、客单价可在影响分析中用于规模/效率传导说明，但不得作为本报告主指标行。
- 19点前链路指标、全链路毛利额及其子指标不得作为本报告主指标行。
- 品效维度指标（品效、商品订购渗透率、定价毛利率、售价价格指数等）不得放入本章节。
- 供应链三率（准确率、准点率、合格率）、活跃供应商数、集采入库占比不得放入本章节。
- 区域、品类、趋势证据只能用于解释全链路毛利率及其下钻链路，不扩展为经营总览。
- CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明。
