# 门店毛利率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code profitRate --full`

## 一、基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 门店毛利率 |
| 指标英文 code | `profitRate` |
| 业务定义 | 销售收入减去销售成本后，占销售收入的比例 |
| 统计逻辑 | 门店毛利额 / 销售额 |
| 业务环节 | 销售经营 |

## 二、指标定位

- 门店毛利率是客数渗透率树中全链路毛利率的直接子指标，属于叶子节点（无下级子指标）。
- 所属维度：客数渗透率维度（用户渗透维度）。
- 报告章节：第三章 用户渗透维度深度拆解。禁止放入第四章（品效维度）、第五章（供应链维度）。
- 所属指标组：全链路盈利。
- 固定拆解链路：`客数渗透率 -> 全链路毛利率 -> 门店毛利率`。
- 归入用户渗透链路中的门店结果指标，反映门店端的毛利效率。

## 三、当前表现与趋势

> 以下数据来自 `qdm-cmr-cli report business`，时间口径 2026-05-24，区域 CN00（全国不含港澳），全品类。

### 3.1 整体表现

| 指标 | 当前值 | 阈值 | 环比变动 | 同比变动 | 阈值达成 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 门店毛利率 | 21.30% | >=20.05% | +2.04pp | -2.21pp | 达标 |

- 当前值 21.30%，高于阈值 20.05%，差额 +1.25pp，处于达标状态。
- 环比上升 2.04 个百分点，反映近期门店端毛利效率有所改善。
- 同比下降 2.21 个百分点，反映与去年同期相比仍有差距，门店毛利率存在结构性下行压力。

### 3.2 趋势表现

> 数据来源：`qdm-cmr-cli report business trend --indicator profitRate`

近 30 天（2026/04/25 ~ 2026/05/24）门店毛利率在小数比率口径下的波动区间为 0.1785 ~ 0.2351（对应 17.85% ~ 23.51%）：

- 趋势低点出现在 2026/05/20（17.85%），随后三个交易日连续回升至 21.30%。
- 趋势高点出现在 2026/05/17（23.51%），为近 30 天峰值。
- 近 30 天内多数时段门店毛利率在 19% ~ 22% 区间震荡，05/17 和 05/24 出现两次相对高点。
- 与去年同期相比，30 天中 25 天当前值高于同期比较值（占比 83%），说明门店毛利率相比去年同期多数时段有所改善，但整体同比仍为负（yoy -2.21pp），主因去年基数中存在更高峰值拉高均值。

## 四、父级链路与传导判断

固定拆解链路：`客数渗透率 -> 全链路毛利率 -> 门店毛利率`

> 以下父级链路数据来自 `qdm-cmr-cli report business indicators`，时间口径 2026-05-24，全国，全品类。

| 层级 | 指标 | 当前值 | 阈值 | 环比变动 | 同比变动 | 传导判断 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 上级指标 | 客数渗透率 | 26.46% | >=30% | +0.07pp | -0.11pp | 未达标，客数渗透率偏低限制门店毛利率的规模效应 |
| 父指标 | 全链路毛利率 | 29.34% | >27.9% | +2.06pp | -2.71pp | 达标，环比改善与门店毛利率同步，同比下滑幅度更深 |
| 当前指标 | 门店毛利率 | 21.30% | >=20.05% | +2.04pp | -2.21pp | 达标，门店端毛利效率是当前全链路毛利率的主要支撑 |

- 门店毛利率（21.30%）占全链路毛利率（29.34%）比重约 72.6%，是构成全链路毛利率的主体。
- 供应链毛利率当前 10.59%，环比 +0.26pp，同比 -1.00pp，供应链端对全链路毛利率的贡献显著低于门店端。
- 全链路毛利率环比 +2.06pp，与门店毛利率环比 +2.04pp 几乎同步，说明门店端毛利改善是驱动全链路毛利率环比改善的核心因素。
- 全链路毛利率同比 -2.71pp，降幅大于门店毛利率的 -2.21pp，说明供应链毛利率同比下滑（-1.00pp）放大了全链路的同比压力。

## 五、诊断规则

### 5.1 诊断逻辑

- 门店毛利率诊断遵循"现象 -> 影响 -> 推断"三段式结构。
- 现象：来自 CLI 的门店毛利率数值、阈值达成、同比环比、区域排名、品类排名或趋势异常点。
- 影响：门店毛利率变化对父指标（全链路毛利率）和上级指标（客数渗透率）的传导后果。
- 推断：基于 CLI 已返回证据的有限根因判断。CLI 只支持趋势或结构异常时，只能写"可能""倾向于"。
- 根因未经 CLI 证据支持时，禁止断言为确定事实。

### 5.2 典型诊断场景

| 场景 | CLI 证据条件 | 诊断方向 |
| :--- | :--- | :--- |
| 门店毛利率达标但同比下降 | 当前 >= 阈值，yoy < 0 | 关注品类或区域结构性拖累，判断是否来自低毛利品类占比升高或区域分化加剧 |
| 门店毛利率环比改善但拖动父指标 | mom > 0 但全链路 mom 弱于门店 | 检查供应链毛利率是否拖累全链路，判断是否供应链端毛利承压 |
| 门店毛利率未达标 | 当前 < 阈值 | 定位拖累区域和品类，判断是否存在系统性毛利管理问题 |
| 趋势中出现异常低点 | trend 中 single-day 显著低于 30 天均值 | 排查当日品类结构或促销活动影响，判断是偶发还是趋势信号 |

### 5.3 区域品类诊断指引

- 区域分化大（最高-最低 > 4pp）时，诊断应关联管理区域特征（粤东粤西为沿海、运营直管的特殊性等），但不扩展为区域经营总览。
- 品类分化大（最高-最低 > 15pp）时，诊断应说明高毛利品类（猪肉）与低毛利品类（肉禽蛋）的天然结构差异，避免归因为经营能力。
- 环比大幅改善（>5pp）的品类（如水果 +6.79pp）需关注是否季节性因素或促销策略调整。

## 六、边界与禁放规则

- 门店毛利率是当前主指标，全链路毛利率、客数渗透率只能用于父级传导，不能替代主指标行。
- 供应链毛利率只作为同组全链路盈利补充，不替代当前指标。
- 门店毛利额、全链路毛利额、供应链毛利额不得作为本报告主指标行，这些属于毛利额专项报告。
- 销售额、客数、客单价、19点前链路指标不得作为本报告主指标行。
- 品效维度指标（品效、商品订购渗透率、定价毛利率、售价价格指数、预期毛利率、出库折让率、时段折扣率、促销折扣率、损耗率、采购价格指数）不得放入本章节。
- 供应链三率（准确率、准点率、合格率）、活跃供应商数、集采入库占比不得放入本章节。
- 区域、品类、趋势证据只能用于解释门店毛利率结构分化和异常，不扩展为经营总览或跨维度分析。
- 本指标固定归入经营分析报告第三章（用户渗透维度深度拆解），禁止放入第四章（品效维度）和第五章（供应链维度）。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据。
