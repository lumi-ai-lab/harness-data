# 时段折扣率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code hourDiscountRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 时段折扣率 |
| 指标英文 code | `hourDiscountRate` |
| 业务定义 | 日清商品在清仓打折时段内产生的折扣金额占全天原价销售额的比例 |
| 统计逻辑 | 时段折扣额 / 原价销售额 |
| 业务环节 | 销售经营 |

## 指标定位

- 时段折扣率是经营分析 `/report/2` 中品效维度下的叶子指标。
- 父指标：定价毛利率（`prePriceProfitRate`）。
- 所属维度：品效维度。
- 所属指标组：定价与折扣策略。
- 报告章节：第四章 品效维度深度拆解。
- 固定拆解链路：`品效 -> 定价毛利率 -> 时段折扣率`。
- 同级指标：促销折扣率（`promotionDiscountRate`）、损耗率（`lostRate`）。

## 下钻子指标

该指标为叶子指标，无子指标。

## 阈值配置

| 属性 | 值 |
| :--- | :--- |
| 阈值类型 | BETWEEN（区间） |
| 阈值下限 | 12.5% |
| 阈值上限 | 14.5% |
| 含义 | 时段折扣率应落在 12.5% ~ 14.5% 区间内，低于下限说明日清折扣力度不足，高于上限说明日清折扣力度过大 |

## 边界与禁放规则

- 时段折扣率固定归入品效维度第四章"定价与折扣策略"板块，不得放入第三章（用户渗透）、第五章（供应链）。
- 该指标用于分析时段折扣对定价毛利率和品效的影响，不得扩展为经营总览报告。
- 销售额、客数、客单价、19点前链路指标、活跃供应商数、三率综合得分、准确率、准点率、合格率不得放入时段折扣率分析章节。
- 区域、品类、趋势证据只能用于解释时段折扣率及其父指标定价毛利率，不得扩展为经营总览。
- 品效、定价毛利率、预期毛利率、出库折让率、促销折扣率、损耗率可作为链路上下文引用，但主指标行只能是时段折扣率。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
