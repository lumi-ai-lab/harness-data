# 出库折让率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code scmPromotionTotalRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 出库折让率 |
| 指标英文 code | `scmPromotionTotalRate` |
| 业务定义 | 出库让利总额占预期出库到店金额的占比 |
| 统计逻辑 | 出库让利总额/(出库到店金额+出库让利总额) |
| 业务环节 | 营销策略 |

## 指标定位

- 出库折让率是经营分析 `/report/2` 的预期毛利率的子指标，属于品效定价毛利率拆解链路的末端叶子指标。
- 所属维度：品效维度。
- 报告章节：第四章 品效维度深度拆解。
- 固定拆解链路：`品效 -> 定价毛利率 -> 预期毛利率 -> 出库折让率`。

## 下钻子指标

该指标为叶子指标，无子指标。

## 当前数据现状（来自 CLI，仅供引用参考；报告优先使用 CLI 最新返回）

| 指标 | 当前值 | valueUnit | 阈值 | 环比 | 同比 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 出库折让率 | 0.0429 (4.29%) | 3 | LE 3.5% | +0.0054 (+0.54pp) | -0.0011 (-0.11pp) |

> valueUnit=3 表示小数比率，需乘以 100 转为百分比显示。出库折让率为负向指标（越低越好），阈值 `LE 3.5` 表示需控制在 3.5% 以内。当前值 4.29% 超出阈值上限。

- 区域排名（出库折让率由高到低，折让越高说明让利越多）：华东（7.36%）、粤西（5.04%）、运营直管（4.25%）、粤东（4.19%）。
- 品类排名（出库折让率由高到低）：冷藏加工（10.60%）、猪肉（5.15%）、水果（4.92%）、蔬菜（3.88%）、预制菜（3.42%）。

## 边界与禁放规则

- 不得放入第三章（用户渗透）、第五章（供应链）。
- 出库折让率固定归入品效定价毛利率拆解，明确归品效，不得放入供应链章节。
- 即使出库折让率名称中包含"scm"，也必须按品效口径处理。
- 商品订购渗透率、售价价格指数、采购价格指数、客数渗透率、活跃供应商数不得作为本报告主指标行。
- 时段折扣率、促销折扣率、损耗率可作为同一父级链路的补充背景，不得替代本报告主指标。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
