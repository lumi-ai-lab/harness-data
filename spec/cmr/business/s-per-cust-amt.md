# 客单价指标报告规则

> 数据来源：`qdm-cmr-cli indicator detail --code perCustAmt --full`

该文件用于经营分析下客数渗透率树中的客单价专项报告。取数固定使用 `qdm-cmr-cli report business`，指标固定为 `客单价` 或 `perCustAmt`。

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 客单价 |
| 指标英文 code | `perCustAmt` |
| 业务定义 | 平均每笔订单的订单金额 |
| 统计逻辑 | 销售额 / 来客数 |
| 业务环节 | 销售经营 |

## 指标定位

- 客单价是客数渗透率（一级核心指标）的一级子指标，属于用户渗透维度下规模类指标。
- 所属维度：用户渗透维度。
- 报告章节：第三章 用户渗透维度深度拆解。
- 固定拆解链路：`客数渗透率 -> 客单价 -> 19点前客单价 -> 19点前单均件数、19点前件单价`。
- 当前值：32.44 元，阈值 >19.8（达标），环比 -5.79%，同比 +35.29%。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 19点前客单价 | `bf19PerCustAmt` | 19点前链路 |
| 二级子指标 | 19点前单均件数 | `bf19AvgPieceNum` | 19点前链路 |
| 二级子指标 | 19点前件单价 | `bf19PerPieceAmt` | 19点前链路 |

## 指标位置

| 指标 | 所属链路 | 报告章节 | 禁止放入位置 |
| --- | --- | --- | --- |
| 客数渗透率 | 父指标 | 父子链路与传导判断 | 作为客单价主指标替代项 |
| 客单价 | 当前指标 | 客单价整体表现 | 品效、供应商专项章节 |
| 19点前客单价 | 子指标 | 早时段客单拆解 | 销售额、客数章节 |
| 19点前单均件数 | 叶子指标 | 早时段客单拆解 | 销售额、客数章节 |
| 19点前件单价 | 叶子指标 | 早时段客单拆解 | 销售额、客数章节 |

## 边界与禁放规则

- 客单价及其下钻链路（19点前客单价、19点前单均件数、19点前件单价）只能放入第三章（用户渗透维度深度拆解），禁止放入第四章（品效维度）和第五章（供应链维度）。
- 客数渗透率只用于父级传导，不能把销售额、客数、毛利链路展开成客单价报告主章节。
- 客数、19点前客数、19点前PI值、19点前复购率及其下游指标不得作为客单价报告主指标行。
- 销售额、19点前销售占比、19点前销售重量、订单满足率不得作为客单价报告主指标行。
- 全链路毛利率、全链路毛利额、门店毛利率、门店毛利额、供应链毛利率、供应链毛利额不得作为客单价报告主指标行。
- 品效、商品订购渗透率、定价毛利率、售价价格指数、活跃供应商数、供应商三率不得放入客单价章节作为主指标行。
- 区域、品类、趋势证据只能用于解释客单价及其下钻链路，不得扩展为经营总览。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
- 不得使用本地 demo、静态样例、经验估算或模板占位符替代 CLI 返回事实。
- 根因必须受 CLI 证据约束，只有趋势或结构异常时只能写有限推断。

## 数据来源规则

- 所有数值、同比、环比、阈值、排名、异常和根因必须来自 CLI 输出。
- 必要来源为 `report business indicators`、`area`、`category`、`trend`。
- 若必要模块失败或 `inject-template` 未成功，不得生成最终报告。
