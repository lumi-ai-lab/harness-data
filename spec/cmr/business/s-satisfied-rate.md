# 订单满足率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code satisfiedRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 订单满足率 |
| 指标英文 code | `satisfiedRate` |
| 业务定义 | 满足分拣标准的订单数占门店订购订单数的比例 |
| 统计逻辑 | 订单满足次数 / 订购订单次数 |
| 业务环节 | 仓储环节 |

## 指标定位

- 订单满足率是19点前销售占比的子指标，属于19点前链路指标组（用户行为链路）。
- 所属维度：用户渗透维度。
- 报告章节：第三章 用户渗透维度深度拆解。
- 叶子指标，无下钻子指标。明确归用户行为链路，不得放入供应链章节。

## 下钻子指标

无。订单满足率为叶子指标。

## 边界与禁放规则

- 订单满足率固定归第三章用户渗透维度（用户行为链路），不得放入品效章节（第四章）或供应链章节（第五章）。
- 品效指标、供应链指标（准确率、准点率、合格率等）不得通过订单满足率交叉引用放入用户渗透章节。
- 区域、品类、趋势证据只能用于解释订单满足率及其对上层指标的贡献，不得扩展为独立拆解章节。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
