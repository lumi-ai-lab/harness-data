# 消费会员数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code buyMemberNum --full`

## 一、基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 消费会员数 |
| 指标英文 code | `buyMemberNum` |
| 业务定义 | 当日发生消费行为的会员人数 |
| 统计逻辑 | 按销售小票标识的会员ID去重计数 |
| 业务环节 | 销售经营 |

## 二、指标定位

- 消费会员数是会员复购率的直接子指标（分母），属于叶子节点（无下级子指标）。
- 所属维度：会员价值与复购转化维度。
- 报告章节：第四章 会员价值与复购转化维度深度拆解。禁止放入第三章（用户规模与分层结构）、第五章（用户触达与渠道效率）。
- 所属指标组：会员复购与消费规模指标。
- 固定拆解链路：`会员复购率 -> 消费会员数`。
- 归入会员价值与复购转化链路中的基础消费规模指标，反映会员消费基础盘。
- 用户报表不支持品类过滤，不输出品类排名、品类拖累或品类贡献。

## 三、当前表现与趋势

> 以下数据来自 `qdm-cmr-cli report user`，时间口径 2026-05-24，区域 CN00（全国不含港澳）。

### 3.1 整体表现

| 指标 | 当前值 | 阈值 | 环比变动 | 同比变动 | 阈值达成 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 消费会员数 | 948,937 | 无预设阈值 | +1.23% | +1.78% | 无阈值 |

- 当前值 948,937 人，无预设阈值。
- 环比上升 1.23%，反映近期消费会员规模有所扩大。
- 同比上升 1.78%，反映消费会员基础盘相比去年同期有所增长。

### 3.2 趋势表现

> 数据来源：`qdm-cmr-cli report user trend --indicator buyMemberNum`

近 30 天（2026/04/25 ~ 2026/05/24）消费会员数在 825,717 ~ 955,682 区间波动：

- 趋势低点出现在 2026/05/20（825,717），随后快速回升。
- 趋势高点出现在 2026/04/26（955,682），接近 95.6 万。
- 近 30 天呈现明显的周期性波动：周末（周五~周日）消费会员数较高（90万+），工作日（周一~周四）消费会员数较低（85万左右）。
- 05/20 为近 30 天最低点，05/21 起连续四天回升至 94.9 万，恢复到周末水平。
- 与去年同期相比，30 天中约 11 天当前值高于同期比较值（占比约 37%），当前整体同比仍为正（+1.78%），反映消费会员数处于改善通道。

**区域表现**（按管理区域，`qdm-cmr-cli report user area --indicator buyMemberNum`）：

- 区域间体量分化显著：粤西（33.5 万）与华东（4.7 万）相差约 7.2 倍。
- 粤西和粤东是消费会员数的主要贡献区域，合计占全国的绝大部分。
- 华东环比（-4.24%）和同比（-4.90%）双降，是拖累全国消费会员数增长的结构性因素。
- 运营直管同比增速高达 +32.43%，但体量极小（2,495），建议关注基数效应。

## 四、父级链路与传导判断

固定拆解链路：`会员复购率 -> 消费会员数`

> 注：会员复购率当前无有效 CLI 返回值，父级传导分析受限。
> 以下仅基于消费会员数自身变化进行分析。

| 层级 | 指标 | 当前值 | 阈值 | 环比变动 | 同比变动 | 传导判断 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 父指标 | 会员复购率 | 无数据 | 无预设阈值 | 无 | 无 | 当前无数据，无法进行传导分析 |
| 当前指标 | 消费会员数 | 948,937 | 无预设阈值 | +1.23% | +1.78% | 消费会员基础盘同比扩大，对复购率分母有扩大效应 |

- 消费会员数作为会员复购率的分母，扩大时会降低复购率（假设复购会员数不变）。
- 需结合复购会员数（当前无数据）综合判断复购率变化方向。
- 消费会员数同比 +1.78%，如果复购会员数增速低于此值，复购率将承压。

## 五、诊断规则

### 5.1 诊断逻辑

- 消费会员数诊断遵循"现象 -> 影响 -> 推断"三段式结构。
- 现象：来自 CLI 的消费会员数数值、同比环比、区域排名或趋势异常点。
- 影响：消费会员数变化对父指标（会员复购率）的传导后果（分母效应）。
- 推断：基于 CLI 已返回证据的有限根因判断。
- 根因未经 CLI 证据支持时，禁止断言为确定事实。

### 5.2 典型诊断场景

| 场景 | CLI 证据条件 | 诊断方向 |
| :--- | :--- | :--- |
| 消费会员数同比扩大但复购率未知 | yoy > 0，复购会员数据缺失 | 警示分母扩大可能稀释复购率 |
| 华东消费会员数双降 | 华东 mom < 0 且 yoy < 0 | 排查华东区域消费会员流失原因 |
| 趋势出现周期性低点后迅速回升 | 工作日低点后周末回升 | 判断为正常周期波动，关注低点是否持续下移 |
| 运营直管同比异常高增长 | yoy > 30% 但体量极小 | 关注基数效应，避免过度解读 |

### 5.3 区域诊断指引

- 区域体量差异大时，诊断应关注主要贡献区域（粤西、粤东）的变化趋势。
- 华东环比同比双降需重点关注，但不应扩展为区域经营总览。
- 运营直管同比增速极高（+32.43%）但体量极小，不应作为区域亮点放大。

## 六、边界与禁放规则

- 消费会员数是当前主指标，会员复购率只能用于父级传导，不能替代主指标行。
- 复购会员数、复购会员消费频次作为同组子指标，只能作为参照补充。
- 活跃用户数、新消费用户数、VIP 分层会员数、休眠/流失指标归入第三章，不得放入本章节。
- 社群用户数、官媒用户数、抖音用户数、可触达用户数、会员数归入第五章，不得放入本章节。
- 会员销售占比、交叉会员数、线上/线下消费会员数作为同维度其他指标组，只能作为参照补充。
- 品类维度指标一律不输出（用户报表不支持品类过滤）。
- 区域、趋势证据只能用于解释消费会员数结构分化和异常，不扩展为经营总览或跨维度分析。
- 本指标固定归入用户运营报告第四章（会员价值与复购转化维度深度拆解），禁止放入第三章（用户规模与分层结构）和第五章（用户触达与渠道效率）。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据。
