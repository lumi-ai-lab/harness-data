# 复购会员数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code repurchaseMemberNum --full`

## 一、基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 复购会员数 |
| 指标英文 code | `repurchaseMemberNum` |
| 业务定义 | 统计周期内至少完成2次及以上消费的会员人数 |
| 统计逻辑 | 统计周期内消费次数>=2的会员ID去重计数（推断） |
| 业务环节 | 销售经营 |

## 二、指标定位

- 复购会员数是会员复购率的直接子指标（分子），属于叶子节点（无下级子指标）。
- 所属维度：会员价值与复购转化维度。
- 报告章节：第四章 会员价值与复购转化维度深度拆解。禁止放入第三章（用户规模与分层结构）、第五章（用户触达与渠道效率）。
- 所属指标组：会员复购与消费规模指标。
- 固定拆解链路：`会员复购率 -> 复购会员数`。
- 用户报表不支持品类过滤。
- **重要提示**：该指标仅在 CLI 返回有值时展示。当前所有数据接口均返回空值或零值，报告生成时应省略此指标。

| 指标 | 当前值 | 阈值 | 环比变动 | 同比变动 | 数据状态 |

| 复购会员数 | 无有效数据 | 无预设阈值 | 无 | 无 | 数据不可用，报告省略 |

## 四、边界与禁放规则

- 复购会员数是当前主指标，会员复购率只能用于父级传导，不能替代主指标行。
- 消费会员数、复购会员消费频次作为同组子指标，只能作为参照补充。
- 活跃用户数、VIP 分层会员数、休眠/流失指标归入第三章，不得放入本章节。
- 社群用户数、官媒用户数、抖音用户数、可触达用户数归入第五章，不得放入本章节。
- 品类维度指标一律不输出。
- 本指标固定归入第四章（会员价值与复购转化维度深度拆解），禁止放入第三章和第五章。
- 该指标仅在 CLI 返回有值时展示；当前无有效数据，报告省略。
- 所有数值必须来自 CLI 输出；CLI 未返回有效值时直接省略。
