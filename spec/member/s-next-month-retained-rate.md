# 次月留存率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code nextMonthRetainedRate --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 次月留存率 |
| 指标英文 code | `nextMonthRetainedRate` |
| 业务定义 | 上个月的新消费会员，在本月继续消费的会员占比 |
| 统计逻辑 | 次月留存会员数 / 上月的新消费会员数 |
| 业务环节 | 用户运营 |

## 指标定位

- 次月留存率是用户运营 `/report/3` 新消费用户数的子指标，属于用户规模与分层结构维度。
- 所属维度：用户规模与分层结构维度。
- 报告章节：第三章 用户规模与分层结构维度深度拆解。
- 指标组：新用户表现指标。
- 固定拆解链路：`活跃用户数 -> 新消费用户数 -> 次月留存率`。
- **重要**：该指标仅在 CLI 返回有值时展示，CLI 未返回则报告中省略该指标行。

## 下钻子指标

该指标为叶子指标，无子指标。

## 边界与禁放规则

- 用户报表不支持品类过滤；不输出品类排名、品类拖累或品类贡献。
- 次月留存率归入用户规模与分层结构维度，固定放入第三章，不得放入第四章（会员价值与复购转化）和第五章（用户触达与渠道效率）。
- 该指标仅在 CLI 返回有值时展示，CLI 未返回时直接省略。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
- 任何指标只能放入其对应维度的主章节，禁止跨维度混放。
