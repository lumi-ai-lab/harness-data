# 会员数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code memberNum --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 会员数 |
| 指标英文 code | `memberNum` |
| 业务定义 | 钱大妈小程序中的会员数量 |
| 统计逻辑 | 会员id去重计数 |
| 数据来源 | 用户报表 `/report/3`（`qdm-cmr-cli report user`） |

## 指标定位

- 会员数是用户报表 `/report/3` 中可触达用户数（`reachMemberNum`）的下游叶子指标。
- 所属维度：用户触达与渠道效率。
- 报告章节：第五章 用户触达与渠道效率深度拆解。
- 父指标：可触达用户数（`reachMemberNum`）。
- 无子指标，为叶子指标。
- 会员数是衡量小程序会员规模和私域用户资产的关键指标，反映会员体系的覆盖能力。

## 下钻子指标

无。会员数为叶子指标，无下钻子指标。

## 边界与禁放规则

- 会员数固定归入"用户触达与渠道效率"维度（第五章），禁止放入第三章（用户规模与分层结构）和第四章（用户价值与复购转化）。
- 不得作为经营分析 `/report/2` 的指标行。
- 会员数不支持下钻品类维度分析（用户报表不支持品类过滤）。
- 区域、趋势证据只能用于解释会员数的表现，不得扩展为用户总览报告。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
