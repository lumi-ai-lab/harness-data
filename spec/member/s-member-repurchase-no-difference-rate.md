# 会员复购率指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code memberRepurchaseNoDifferenceRate --full`

## 一、基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 会员复购率 |
| 指标英文 code | `memberRepurchaseNoDifferenceRate` |
| 业务定义 | 统计周期内，至少完成2次及以上消费的会员人数占所有消费会员总数的比，衡量会员的忠诚度 |
| 统计逻辑 | 复购会员数 / 会员数 |
| 业务环节 | 销售经营 |

## 二、指标定位

- 会员复购率是一级核心指标（showTable），属于会员价值与复购转化维度的总纲指标。
- 所属维度：会员价值与复购转化维度。
- 报告章节：第二章 核心指标总览、第四章 会员价值与复购转化维度深度拆解。禁止放入第三章（用户规模与分层结构）、第五章（用户触达与渠道效率）。
- 所属指标组：会员复购与消费规模指标。
- 固定拆解链路：`会员复购率 -> 复购会员数、消费会员数、复购会员消费频次`。
- 下级子指标：复购会员数（`repurchaseMemberNum`）、消费会员数（`buyMemberNum`）、复购会员消费频次（`memberRepurchaseTranTimes`）。
- 无父指标，作为一级核心指标独立展示。
- 用户报表不支持品类过滤，不输出品类排名、品类拖累或品类贡献。
- **重要提示**：该指标仅在 CLI 返回有值时展示。当前所有数据接口（`indicators`、`area`、`trend`）均返回空值或零值，报告生成时应省略此指标。

## 四、下钻子指标

会员复购率可下钻为以下三个子指标：

| 子指标 | indicatorCode | 关系 | 数据状态 |
| :--- | :--- | :--- | :--- |
| 复购会员数 | `repurchaseMemberNum` | 分子，叶子节点 | 无数据 |
| 消费会员数 | `buyMemberNum` | 分母，叶子节点 | 有数据（948,937） |
| 复购会员消费频次 | `memberRepurchaseTranTimes` | 复购深度，叶子节点 | 无数据 |

> 注：消费会员数 CLI 有返回实际值，复购会员数和复购会员消费频次当前无有效数据。

## 五、诊断规则

### 5.1 诊断逻辑

- 会员复购率诊断遵循"现象 -> 影响 -> 推断"三段式结构。
- 现象：来自 CLI 的会员复购率数值、同比环比、趋势异常点。
- 影响：会员复购率变化对会员粘性和忠诚度的评估，向子指标的传导。
- 推断：基于 CLI 已返回证据的有限根因判断。
- 根因未经 CLI 证据支持时，禁止断言为确定事实。

### 5.2 典型诊断场景

| 场景 | CLI 证据条件 | 诊断方向 |
| :--- | :--- | :--- |
| 会员复购率下降 | 当前值下降，mom < 0 | 排查是复购会员数减少还是消费会员数扩大（分母效应）导致 |
| 会员复购率上升 | 当前值上升，mom > 0 | 判断复购会员增速是否高于消费会员增速，评估会员粘性是否在改善 |
| 复购会员消费频次下降 | 频次下降但复购率持平 | 判断是否存在复购用户消费频次下降但复购覆盖面扩大的结构性变化 |
| 区域复购率分化 | 区域间复购率差异大 | 判断高复购率区域是否存在集中消费、低复购率区域是否存在消费流失 |

### 5.3 诊断限制

- 当前所有数据接口均返回空值/零值，无法进行实际诊断。
- 子指标中仅消费会员数有实际数据，复购会员数和复购会员消费频次均无数据。

## 六、边界与禁放规则

- 会员复购率是当前主指标，复购会员数、消费会员数、复购会员消费频次只能作为下钻子指标，不能替代主指标行。
- 活跃用户数、新消费用户数、VIP 分层会员数、休眠/流失指标归入第三章，不得放入本章节。
- 社群用户数、官媒用户数、抖音用户数、可触达用户数、会员数归入第五章，不得放入本章节。
- 会员销售占比、交叉会员数、线上/线下消费会员数作为同维度其他指标组，只能作为参照补充，不替代当前指标。
- 品类维度指标一律不输出（用户报表不支持品类过滤）。
- 区域、趋势证据只能用于解释会员复购率结构分化和异常，不扩展为经营总览或跨维度分析。
- 本指标固定归入用户运营报告第二章（核心指标总览）和第四章（会员价值与复购转化维度深度拆解），禁止放入第三章（用户规模与分层结构）和第五章（用户触达与渠道效率）。
- 该指标仅在 CLI 返回有值时展示；当前所有接口均返回空值/零值，报告生成时应省略此指标。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行、指标组或段落直接省略，不写缺失说明，不保留占位符，不使用本地 demo 数据。
