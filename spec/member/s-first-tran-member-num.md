# 新消费用户数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code firstTranMemberNum --full`

## 基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 新消费会员数 |
| 指标英文 code | `firstTranMemberNum` |
| 业务定义 | 用户的历史首次消费时间处于统计周期内的用户数 |
| 统计逻辑 | 统计周期内，产生了首次消费的会员id计数 |
| 业务环节 | 用户运营 |

## 指标定位

- 新消费用户数是用户运营 `/report/3` 活跃用户数的子指标，属于用户规模与分层结构维度。
- 所属维度：用户规模与分层结构维度。
- 报告章节：第三章 用户规模与分层结构维度深度拆解。
- 指标组：新用户表现指标。
- 固定拆解链路：`活跃用户数 -> 新消费用户数 -> 新客首单客单价/次月留存率`。

## 下钻子指标

| 层级 | 指标 | code | 所属指标组 |
| :--- | :--- | :--- | :--- |
| 一级子指标 | 新客首单客单价 | `firstTranMemberPerCustAmt` | 新用户表现指标 |
| 一级子指标 | 次月留存率 | `nextMonthRetainedRate` | 新用户表现指标 |

## 边界与禁放规则

- 用户报表不支持品类过滤；不输出品类排名、品类拖累或品类贡献。
- 新消费用户数归入用户规模与分层结构维度，固定放入第三章，不得放入第四章（会员价值与复购转化）和第五章（用户触达与渠道效率）。
- 该指标为活跃用户数的子指标，在报告中需作为用户分层结构的一部分展示。
- 所有数值、同比、环比、排名、异常和根因必须来自 CLI 输出；CLI 未返回的指标行直接省略。
- 任何指标只能放入其对应维度的主章节，禁止跨维度混放。
