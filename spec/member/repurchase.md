# 会员复购规则

- 会员复购率、消费会员数、复购会员数、复购会员消费频次、会员销售占比归入会员价值与复购转化。
- 会员复购相关指标不得放入用户规模与分层结构或用户触达与渠道效率章节。
- 指标配置存在但 CLI 没有返回值，不等于指标值为 0；最终报告应省略无值指标。
