# 抖音用户数指标详情

> 数据来源：`qdm-cmr-cli indicator detail --code douyinUserNum --full`

## 一、基本信息

| 属性 | 值 |
| :--- | :--- |
| 指标中文名 | 抖音用户数 |
| 指标英文 code | `douyinUserNum` |
| 业务定义 | 统计周期内，最后一天的抖音钱大妈QDM的粉丝数量 |
| 统计逻辑 | 抖音公众号粉丝数量 |
| 业务环节 | 用户触达与渠道效率 |

## 二、指标定位

- 抖音用户数是可触达用户数的直接子指标，属于叶子节点（无下级子指标）。
- 所属维度：用户触达与渠道效率维度。
- 报告章节：第五章 用户触达与渠道效率维度深度拆解。禁止放入第三章（用户规模与分层结构）、第四章（会员价值与复购转化）。
- 所属指标组：渠道触达指标。
- 固定拆解链路：`可触达用户数 -> 抖音用户数`。
- 归入用户触达与渠道效率链路中的内容平台触达指标，反映抖音渠道的粉丝覆盖能力。
- 用户报表不支持品类过滤，不输出品类排名、品类拖累或品类贡献。
- **重要提示**：该指标仅在 CLI 返回有值时展示。当前所有数据接口（`indicators`、`area`、`trend`）均返回空值或零值，报告生成时应省略此指标。

## 三、当前表现

> 当前（2026-05-24）所有数据接口均未返回有效值：
> - `indicators` 子命令：items 中不包含该指标。
> - `area` 子命令：rows 为空数组。
> - `trend` 子命令：所有 30 天 current 和 compare 均为 0。

| 指标 | 当前值 | 阈值 | 环比变动 | 同比变动 | 数据状态 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 抖音用户数 | 无有效数据 | 无预设阈值 | 无 | 无 | 数据不可用，报告省略 |

## 四、边界与禁放规则

- 抖音用户数是当前主指标，可触达用户数只能用于父级传导，不能替代主指标行。
- 社群用户数、官媒用户数、会员数作为同组渠道触达指标，只能作为参照补充，不替代当前指标。
- 活跃用户数、新消费用户数、VIP 分层会员数、休眠/流失指标归入第三章，不得放入本章节。
- 会员复购率、消费会员数、复购会员数、复购会员消费频次、会员销售占比、交叉会员数、线上/线下消费会员数归入第四章，不得放入本章节。
- 品类维度指标一律不输出（用户报表不支持品类过滤）。
- 本指标固定归入用户运营报告第五章（用户触达与渠道效率维度深度拆解），禁止放入第三章（用户规模与分层结构）和第四章（会员价值与复购转化）。
- 该指标仅在 CLI 返回有值时展示；当前所有接口均返回空值/零值，报告生成时应省略此指标。
- 所有数值必须来自 CLI 输出；CLI 未返回有效值时，直接省略指标行，不写缺失说明，不保留占位符，不使用本地 demo 数据。
