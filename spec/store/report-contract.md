# 门店管理指标归属规范

> 该文件是门店管理深度报告的权威指标归属说明。取数前必须读取，用于取数和业务规则判断；signal 后只注入匹配 template 正文。

## 硬规则

- 门店管理报告只使用 signal 后二阶段注入的 template 章节结构；signal 前不读取、不使用 template。
- 品类口径固定为全品类，不做品类下钻，不输出品类排名、品类拖累或品类贡献。
- 区域支持下钻；未指定区域时固定为全国（不含港澳）。
- `核心指标总览` 只展示两大一级指标：营业门店数、门店净利润。
- 门店规模、开闭店、停业、待开业相关指标归入门店规模与健康度。
- 门店净利润、盈亏平衡点、成本、坪效、人效相关指标归入门店盈利与运营效率。
- 任何指标只能放入其对应维度的主章节，禁止跨维度混放。
